# Ограничения и пробелы проверки

Состояние 2026-09-17, статическое исследование.

- Каталог содержит 149 записей; импорт и наличие unit-тестов не подтверждают живую работоспособность всех моделей.
- Ограничения исходного видео не полностью проверяются по метаданным; единицы provider costTime определяются эвристикой.
- Поиск модели задачи в main.js использует providerId + apiModel, а не уникальный id варианта. Для вариантов одного API-имени следует отдельно проверить правильность восстановления адаптера/режима.
- Поля search/filter записываются в черновик, но точное восстановление не реализовано в restoreWorkspaceDrafts.
- History сериализует запись внутри экземпляра; межпроцессной защиты нет.
- Проверка отправителя IPC применяется не ко всем обработчикам; системный аудит безопасности не проводился.
- UI smoke в режиме --packaged по умолчанию ищет dist/win-unpacked; для единственного дистрибутива требуется AI_CLIENT_PACKAGED_PATH (см. runbook).
- При первоначальном исследовании зависимости отсутствовали. После установки и исправления сети: 45 unit-тестов прошли, сборка dist/queue-header обновлена. UI smoke запускался и остановился на `Local video failed`; полной успешной UI-проверки нет.
- SQLite рекомендован порогом GI (>50 текстовых файлов); индекс не активирован. Векторный поиск не обоснован текущим объёмом.
- Не подтверждены живые цены и внешние API. Пользовательские данные и секреты не читались.
