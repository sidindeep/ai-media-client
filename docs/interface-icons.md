# Иконки интерфейса

Для сайта выбран **Iconoir Regular 7.12.1**: сетка 24×24, контур 1,5,
скруглённые линии, цвет наследуется от элемента интерфейса.

Источник: [Iconoir](https://iconoir.com/),
[официальный репозиторий](https://github.com/iconoir-icons/iconoir).
Лицензия MIT сохранена в `web/public/iconoir/LICENSE.txt`.

## Использование

- В Vue использовать `AppIcon` из `web/src/components/AppIcon.vue`:
  `<AppIcon name="download" />`.
- Имена описывают действия: `project`, `chat`, `generate`, `parameters`,
  `credits`, `download`, `delete`. Полная карта — `web/public/iconoir/manifest.json`.
- В HTML использовать `svg.app-icon` с `viewBox="0 0 24 24"` и
  `<use href="/app/iconoir/sprite.svg#download"></use>`.
- Базовый размер — 18 px; плотные элементы используют 15–16 px,
  крупные превью — 24–36 px. Сохранять квадратные пропорции.
- Общие стили находятся в `public/theme.css`. Активность показывается цветом,
  фоном и состоянием кнопки, без замены контуров на другой набор.
- Декоративные SVG имеют `aria-hidden="true"` и `focusable="false"`.
  Кнопка без текста обязана иметь локализованный `aria-label`.
- Центрирование иконок не должно менять адаптивную видимость кнопок. Крестик
  правой панели показывается только в выдвижном режиме (721–1050 px).

## Границы

Иконки заменены в студии, каталоге моделей, истории, редакторе,
аккаунте и оплате, диалогах, лендинге, входе и общих элементах legacy/admin.
Логотипы брендов, аватары, индикаторы загрузки,
арифметические знаки и стрелки в текстовых описаниях сохраняют своё назначение.

В основных настройках генерации пропорции отображаются геометрическим контуром
в сетке 24×24 и толщиной 1,5. Стандартные форматы сохраняют фактическое отношение
сторон. Для вытянутых форматов вроде 1:8 и 8:1 короткая сторона ограничена снизу
6 единицами, чтобы контур в размере 20 px оставался рамкой, а не линией;
точное отношение сторон сохраняется в подписи. Для auto/adaptive
используется `fullscreen` (expand). Это индикатор значения в стиле набора,
реализованный в `AspectRatioIcon.vue`. Меню `AspectRatioPicker` показывает его
для каждого варианта в режимах изображений и видео, поддерживает клавиатуру.
Пропорции, разрешение и длительность используют общий `ParameterPicker.vue`:
одинаковые строки 34 px, иконки 20 px, скругления, подсветку, галочку выбора,
прокрутку и управление клавиатурой. Системный select скрыт и сохраняет значения
для совместимости; видимое меню полностью оформляется общими стилями.
Варианты размещаются в одну строку, галочка выбора стоит слева. Выбор и
наведение отмечаются полупрозрачной фиолетовой заливкой без яркой обводки;
описания пропорций сохраняются в доступном названии варианта.
Ширина меню определяется самым длинным значением с учётом колонок и отступов,
минимум — 88 px; ширина поля на неё не влияет. Галочка занимает постоянную
колонку 16 px, контур пропорции — 20 px, промежутки — 6 px. Галочка выбора
использует встроенную геометрию Iconoir check и меняет только видимость;
её отображение не зависит от загрузки внешнего SVG. Подсветка выбранного пункта
сильнее подсветки наведения; движение мыши снимает клавиатурную подсветку.
В вариантах разрешения и длительности показаны текст и галочка выбора; иконки
остаются в закрытых полях. Высота меню учитывает строки, отступы и рамку,
поэтому полоса прокрутки появляется только при фактическом переполнении.
Для пропорций `menuIcons` всегда включён. В общем picker значение по умолчанию
равно `true`; только разрешение и длительность передают `false`.
Контуры нормализованы по площади, чтобы широкие и вертикальные форматы не
выглядели мельче квадрата. Ячейка иконки в меню и в поле — 20 px;
центрирование и толщина линий сохраняются.
Разрешение обозначается `resolution` (frame-tool), длительность — `duration` (timer).
Кнопка дополнительных настроек использует шестерёнку `settings`.
Панель изображений (`ImageSettingsBar.vue`) использует те же компактные поля,
что и видео: подписи сверху, модель и параметры в одной строке. Каждый параметр
выводится один раз по текущему провайдеру. Дополнительные параметры открывает
шестерёнка; для моделей без дополнительных полей она скрыта.
Иконки стоят рядом со значениями; числа, единицы и текстовые подписи сохраняются.
Для полей с общим именем `size`/`format` тип определяется по вариантам значений:
пропорции или размеры в пикселях. Неизвестные варианты сохраняют текстовую подпись.

73 локальных SVG и спрайт поставляются вместе с Vite-сборкой; CDN и новая
runtime-зависимость не нужны. Каждый файл сохраняет геометрию исходного набора.
Manifest фиксирует пакет, версию, upstream-имена и SHA-256 отдельных SVG.
Добавляя иконку, обновить исходный SVG, manifest и соответствующий symbol
в спрайте. Предыдущая подборка Lucide в `web/public/ui-icons/` остаётся
материалом сравнения; рабочий интерфейс использует `iconoir/`.

## Проверка

После изменений выполнить обязательную Docker-пересборку из runbook.
Проверить `/api/health`, доступность `/app/iconoir/sprite.svg`, SVG MIME,
наличие всех используемых symbol ID и проверку типов Vue при сборке.
Размер и цвет задаются элементом; геометрия не должна изменяться от
унаследованных CSS-правил старых иконок.
Иконки в общем picker находятся внутри кнопок; фон поля при наведении
не должен перекрывать их.
