# Интеграции и источники

Проверено по локальному коду 2026-09-17; живые API не вызывались.

| Система | Роль и контракт | Граница |
| --- | --- | --- |
| Kie.ai — https://kie.ai | Единственный текущий провайдер; API https://api.kie.ai | Ключ в главном процессе, Bearer для генерации/статуса/баланса |
| Kie uploads | https://kieai.redpandaai.co/api/file-stream-upload, multipart | Передаются выбранные пользователем файлы, ключ провайдера; ожидается HTTPS URL |
| Kie Market | /api/v1/jobs/createTask, /api/v1/jobs/recordInfo | POST не повторять автоматически при неизвестном результате |
| Kie balance | /api/v1/chat/credit | Снимок баланса для сверки, не распределение расхода по задачам |
| Kie pricing | /client/v1/model-pricing/page | Публичные тарифы, без пользовательских входов/ключа |
| Kie account pricing | /api/v1/playground/getConsumeCredits | Авторизованная отдельная browser partition; не тот же секрет, что API-ключ |
| GI — https://github.com/Dimosfil/general-instructions.git | Источник скопированных инструкций | Не dependency/submodule/runtime приложения |

Специальные пути Veo/Runway/Flux/4o берутся из модели (kie-special.json) и нормализуются adapters.js. Источник истины по актуальному провайдерскому контракту — документация Kie; локальные импорты являются снимками. Обновление каталога ручное через scripts/import-*.js, не автоматически при старте.

Общий API-запрос имеет таймаут 60 секунд, upload — 180 секунд. Ключи шифруются Electron safeStorage; если шифрование недоступно, сохранение/расшифровка запрещены. Не сохранять ключи, cookies или содержимое пользовательской истории в памяти проекта.

С 2026-09-17 src/network.js повторяет сетевые сбои загрузки исходника и GET
до трёх попыток с задержками 1 и 2 секунды. Каждая попытка получает отдельный
таймаут. HTTP-ошибки не повторяются. POST создания генерации выполняется
однократно: при потере ответа сохраняется unknown. Сообщение содержит этап
операции и совет проверить связь, без ключей, URL и сырого текста исключения.
Проверки: test/network.test.js и test/queue.test.js (19 тестов прошли).

Браузер Kie изолирован persistent partition; очистка затрагивает его storage/cache и кэш цен, а не общий браузер пользователя. Навигация ограничивается кодом allowedNavigation. Контракт сессии покрыт test/kie-session.test.js; это не независимый аудит безопасности.

Внешних рабочих каталогов и разрешённых абсолютных путей зависимости нет. Task-manager не подключён; опциональный выбор WorkNest/none предложен отдельно и не блокирует локальную документацию.
