# APIMart: администраторский текстовый маршрут

Статус 2026-09-28: каталог доступен. Он ошибочно относит `babbage-002` и
`davinci-002` к `chat`; первый вернул 404 на `/chat/completions`, тогда как
`gpt-4o-mini` ответила 200. Оба legacy ID исключаются из каталога приложения.

## Контракт

- `APIMART_API_KEY` хранится в серверной среде. `src/server/config.js` передаёт
  его только `src/providers/apimart/client.js`; клиентский каталог содержит
  только ID и название модели.
- Только администратор может читать `/api/apimart/models`, создавать и читать
  `/api/apimart/jobs`. Модели категории `chat` берутся из ограниченного ключом
  каталога APIMart и кешируются на 10 минут. Нет ручного добавления модели по
  строке из браузера. `babbage-002` и `davinci-002` исключены как несовместимые
  с маршрутом чата. При отсутствии сохранённого выбора UI предпочитает
  `gpt-4o-mini`, если она есть. Другие категории скрыты до реализации их протоколов.
- Текстовый запрос содержит UUID, модель и непустой промпт до 20 000 символов.
  `requestId` связывает повтор с прежней записью; другая модель, промпт или
  чат с тем же ID отклоняются. Отправка использует `stream: false`.
- Задача хранится в namespace `apimart` выбранного аккаунта. История,
  страницы, delta-чтение и удаление архивного чата включают этот namespace.
  События создания, отправки и исхода пишутся в общий журнал.
- Внутренний тариф пока отсутствует. Администратор платит в APIMart напрямую;
  кредитный кошелёк приложения не затрагивается. Обычным пользователям API
  запрещён. В ответе без текста, при неоднозначном сбое или перезапуске
  состояние `unknown`; автоматического повтора POST нет.

Реализация: `src/providers/apimart/client.js`,
`src/services/apimart-jobs.js`, `src/server/http.js`,
`src/services/generation-history.js`, `web/src/stores/studio.ts`.
Пользовательское описание: `docs/apimart.md`.
