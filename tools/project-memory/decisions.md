# Решения и инварианты

- Корень проекта определяется расположением AGENTS.md; машинные абсолютные пути запрещены пользовательским решением.
- Единственная сборка dist/queue-header; beforePack guard нельзя отключать.
- Локальный клиент вызывает внешнего провайдера, не выполняет модель на устройстве.
- Провайдер, описание модели и API-адаптер разделены; ручные исправления каталога переживают импорт.
- Неопределённый POST не повторяется: предпочтительна ручная сверка вместо повторной оплаты.
- Пауза новых отправок не останавливает наблюдение удалённых задач.
- Сохранение результата и факт генерации независимы.
- Неизвестная стоимость не равна нулю; баланс не распределяется по моделям.
- Документы описывают существующий код, не вводят новую функциональность. Предыдущие мотивы решений, не подтверждённые историей, не реконструировались.
