# Абстракция медиа — собственность приложения

Решение пользователя 2026-09-17: общий функциональный контракт принадлежит
AI Media Client. Отдельный проект llm_providers содержит реализации
провайдеров с их родными форматами данных, без нашей медиа-абстракции.

Реализована изолированная основа: web-tg/src/media/index.mjs — интерфейс/реестр;
kie-adapter.mjs — перевод через внедрённый Kie-клиент;
kie-models.mjs — отображение семантических полей модели в Kie Market input.
Контракт и текущие ограничения: docs/media-provider-boundary.md.

Очередь, история, исходники, черновики и стоимости остаются у приложения.
Библиотека обеспечивает только протокол/транспорт Kie. Адаптер приложения
нормализует данные и убирает сырые сообщения провайдера перед UI.
Ошибка неоднозначной отправки сохраняет outcome=unknown. Статусы и результаты
валидируются; неизвестная стоимость не превращается в ноль.

Проверки: web-tg/test/media-contract.test.js, шесть offline-сценариев. Подключение
внешнего пакета, переключение Electron на этот слой, перенос полного каталога
и специальных Kie API пока не выполнялись. Не заявлять завершённую миграцию.
