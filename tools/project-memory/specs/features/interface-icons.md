# Контракт иконок интерфейса

Решение владельца от 2026-10-03: использовать Iconoir Regular вместо смеси
самописных SVG и текстовых символов. Дизайн: 24×24, stroke 1,5, currentColor.

## Владение и точки входа

- `web/public/iconoir/manifest.json` — карта семантических имён, upstream-имён,
  версии 7.12.1 и контрольных сумм; рядом оригинальные SVG, sprite и MIT license.
- `web/src/icons.ts` — тип `IconName`, ссылка на symbol и создание SVG для
  анимации отправки задачи вне Vue.
- `web/src/components/AppIcon.vue` — общий декоративный SVG без событий.
- `public/theme.css` — общие размеры; отдельные компоненты задают размеры
  внутри существующих кнопок. Vite поставляет ассеты по `/app/iconoir/`.

## Инварианты

Одинаковое действие использует одинаковый symbol. Проект — folder, чат —
chat-bubble, генерация — magic-wand, дополнительные настройки — settings,
кредиты — coins.
Основные параметры генерации: пропорции — контур с отношением сторон
(`AspectRatioIcon.vue`), auto/adaptive — expand, разрешение —
`resolution` (frame-tool), длительность — `duration` (timer). Иконки дополняют
значения и подписи; wire values, допустимые варианты и ограничения не меняются.
Список пропорций использует `AspectRatioPicker` в изображениях и видео; каждый
пункт и выбранное значение имеют свой контур.
Контуры пропорций имеют одинаковую площадь для стандартных форматов, а длинная
сторона ограничена 22 единицами в SVG 24×24. Короткая сторона не меньше 6 единиц:
экстремальные 1:8/8:1 остаются открытыми рамками при размере 20 px. Для стандартных
форматов отношение сторон точное; для экстремальных — оптическая коррекция,
точное значение сохраняется в тексте. В меню и в поле одинаковые ячейки 20 px;
центрирование, углы и толщина линий сохраняются.
Пропорции, разрешение и длительность используют `ParameterPicker.vue` с общими
строками 34 px, колонками иконок 20 px, цветами, подсветкой, скруглениями и
галочкой выбора. AspectRatioPicker и DurationPicker адаптируют только значения
и подписи. Native select скрыт для совместимости; видимое меню общее.
Меню компактное: значение в одной строке, галочка слева, полупрозрачная
фиолетовая подсветка выбора и наведения. Название формы сохраняется в aria-label.
Ширина меню — max-content (минимум 88 px, максимум ширина экрана минус 20 px),
независимо от ширины trigger. Позиционирование использует фактическую ширину меню.
Колонки: check 16 px, опциональная иконка 20 px, текст; gap 6 px.
Check содержит исходный path Iconoir встроенно, остаётся смонтированным и меняет
видимость через v-show. Выбор сохраняет свою подсветку при наведении;
клавиатурная подсветка включается навигацией и снимается движением указателя.
Варианты разрешения и длительности не повторяют иконку поля (`menuIcons=false`),
а варианты пропорций показывают свои контуры.
`menuIcons` имеет явный default `true` (Boolean без default Vue приводит к false).
AspectRatioPicker явно передаёт true, чтобы всегда сохранять контуры вариантов.
Расчёт высоты включает 12 px отступов и 2 px рамки; overflow-y:auto показывает
скролл только при переполнении.
Панель изображений использует `ImageSettingsBar.vue` и общие стили панели видео.
`image-settings.ts` выбирает основные поля только текущего провайдера и исключает
повторные ключи. В Composer основные поля изображения не выводятся повторно
через старые pills; настройки APIMart не отображаются для Kie. Дополнительные
поля изображения открываются шестерёнкой, а поля Codex используют ту же панель.
Брендовые логотипы и буквенные резервные изображения не заменяются UI-иконками.
Функции, обработчики событий, порядок действий и доступность моделей не меняются.
SVG не получает фокус и скрыт от assistive technology; имя задаёт кнопка/ссылка.
Общее центрирование иконок не переопределяет адаптивную видимость контролов.
Крестик правой панели виден только в выдвижном режиме (721–1050 px) и закрывает
панель через `rightOpen`; на широком экране и в мобильной вкладке результатов
он скрыт. Широкая панель остаётся постоянно видимой.
В избранном сохраняются `aria-pressed`, цвет и различимая подложка активной кнопки.
Динамическая смена режима входа и видимости пароля сохраняет SVG и меняет
его смысл вместе с доступным названием.

Проверка сборки и HTTP-доступности ассетов выполняется на свежем Compose;
визуальный обход сайта автоматически не запускается по правилу проекта.
