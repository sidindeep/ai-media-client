# Проекты и чаты веб-студии

## Границы данных

- Каждый проект и чат принадлежит одному media_accounts.id.
- Проект хранит имя, владельца, даты создания/изменения и archived_at.
- Чат хранит имя, необязательный проект, контекст JSON, даты и archived_at.
- Генерация, черновик и сохранённый исходник могут содержать projectId и chatId.
- Виртуальный системный чат system:recent показывает существующую историю без миграции старых записей.

## Контракт операций

- GET/POST/PATCH /api/projects и POST /api/projects/:id/archive выполняются только в account scope.
- GET/POST/PATCH /api/chats, POST /api/chats/:id/move и POST /api/chats/:id/archive выполняются только в account scope.
- Архивирование помечает проект/чат датой и не удаляет записи генераций, исходники или результаты.
- Перед привязкой генерации проверяется существование и принадлежность проекта/чата аккаунту; архивные рабочие области не принимают новые генерации.
- Если указан только чат проекта, сервер восстанавливает projectId из чата. Несовпадение проекта и чата отклоняется.
- Администратор может выбрать другой аккаунт только через существующий account-scope механизм; пользователь не может подменить tenant.

## Рабочий процесс UI

- Левая панель имеет вкладки «Чаты» и «Проекты», поиск и сворачивание.
- Чаты группируются по дате; «Ранее» остаётся системным представлением всей истории.
- Для чата и проекта доступны переименование, перенос чата и архивирование через контекстное меню.
- Выбранный чат становится единым контекстом composer, очереди, результата и истории.

## Composer и результаты

- Composer закреплён внизу центральной области и переключается между текстом, изображением, видео и аудио.
- Для Codex доступны модель, уровень рассуждений, скорость и формат изображения; для Kie поля строятся из каталога модели, включая исходники и дополнительные параметры.
- Количество экземпляров умножает серверную котировку, а кнопка запуска показывает итоговую стоимость до отправки.
- Черновик промпта, режим, модель, параметры и исходники сохраняются отдельно для каждого чата.
- Правая панель разделяет очередь выбранного чата и результаты; активность других чатов показывается отдельным индикатором.
- Очистка очереди отменяет только ожидающие задачи и не скрывает уже выполняющуюся генерацию.
- Результат показывает медиа, модель, время, стоимость и токены; повтор и редактирование сначала возвращают параметры в composer и не запускают платную операцию автоматически.

## Адаптивность

- На широком экране одновременно видны левая панель, рабочая область и правая панель.
- На среднем экране правая панель открывается поверх рабочей области.
- На телефоне чаты, рабочая область и результаты представлены отдельными экранами с нижней навигацией; composer остаётся доступным без вложенной прокрутки.
- Последний активный чат и проект восстанавливаются из локального состояния браузера, а серверный черновик восстанавливает содержимое composer.

## Проверки

- API-тесты проверяют tenant isolation, создание, переименование, перенос, архивирование, chat-scoped draft и сохранение projectId/chatId у генераций.
- UI smoke проверяет загрузку Vue SPA, восстановление чата и черновика, четыре режима composer, стоимость и телефонную навигацию.
- При выпуске обязательны Vue type-check, серверные тесты, сборка, Docker health и визуальная проверка широкого, среднего и телефонного состояния.
