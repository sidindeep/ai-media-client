# Тестирование проекта

Папка `test/` содержит автоматические тесты и точку входа для ручных проверок UI.
Все пути и команды разрешаются от корня проекта, содержащего `AGENTS.md`.

| Что нужно проверить | С чего начать |
| --- | --- |
| Ручной обход интерфейса агентом | [Инструкции ручного UI-тестирования](manual-ui/README.md) |
| Предварительные цены и доступность моделей без генераций | [Сценарий, готовый промпт и настройки](../docs/model-ui-audit-prompt.md) |
| Автоматические тесты, контейнеры, health и диагностика | [Команды и порядок проверки](../tools/AGENT_RUNBOOK.md) |
| Правила проекта и общей БД | [AGENTS.md](../AGENTS.md) |

`*.test.js`/`*.test.mjs` — автоматические тесты; `browser-e2e.cjs` и
`web-ui-smoke.cjs` — браузерные сценарии изолированного тестового окружения.
Они не являются исполнителями ручного живого аудита цен. Не подключай их
к рабочей общей БД и не выдавай результат с подменами за проверку живого провайдера.

Отчёты и screenshots сохраняй в документированных ignored-папках `outputs/`,
приватные backup — отдельно по правилам сценария. В `test/` не клади пользовательские
черновики, секреты, медиа, сырые журналы или результаты отдельных запусков.
