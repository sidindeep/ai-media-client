# Создание роликов

В веб-приложении откройте **Создать ролик** в боковом меню (`/app/movie`).
Добавьте титры, изображения PNG/JPEG/WebP и клипы MP4/WebM с устройства или
сохранённые результаты своего аккаунта из списка «Мои результаты».
Измените порядок кнопками ↑/↓, текст и длительность каждой сцены. Выберите
вертикальный, горизонтальный или квадратный формат, цвет фона, музыку и звук
исходных клипов. Просмотрите ролик и нажмите **Собрать MP4**, затем **Скачать MP4**.
Экспорт можно отменить.

Для импорта источников вставьте ссылку в поле **Ссылка на папку или файл** и
нажмите **Загрузить фото и видео**. Все подходящие файлы добавляются сценами
по 5 секунд в порядке списка. Публичные папки Яндекс Диска обходятся вместе
с вложенными папками; вход в Яндекс не нужен. Показываются прогресс, количество
добавленных/пропущенных файлов и достижение лимита. Отмена сохраняет уже
загруженные сцены. Это разовая загрузка по кнопке; наблюдения за папкой нет.

Google Drive использует официальный Drive API. Администратор должен включить
Drive API в Google Cloud и задать серверный `MEDIA_GOOGLE_DRIVE_API_KEY` в `.env`,
после чего пересоздать сервис. Ключ не передаётся в браузер. Поддерживаются
публичные папки и файлы; закрытые папки требуют отдельной OAuth-интеграции.
Без ключа редактор явно сообщает, что импорт Google Drive не настроен.

Для другого хранилища поддерживаются публичная прямая HTTPS-ссылка на фото/видео,
HTML-каталог с ссылками на файлы, текстовый список URL (по одному на строку)
или JSON `{"files":[{"url":"https://example.com/photo.jpg","name":"photo.jpg"}]}`.
Произвольная страница облачного сервиса, ZIP-архив или закрытая папка не
являются списком файлов и требуют адаптера соответствующего сервиса.

Ограничения импорта: до свободных мест в 20 сценах, 100 МБ на файл и 300 МБ
за одну загрузку. Обход ограничен 50 запросами, 5 уровнями вложенности;
при достижении ограничений интерфейс сообщает о неполном импорте.
Видео должно декодироваться браузером: расширение MP4 само по себе не
гарантирует поддержку кодека, например HEVC. Импорт не перекодирует клипы.
Удалённые источники проходят через сервер в память браузера; в серверной БД
или истории они не сохраняются. Сервер проверяет HTTPS, DNS/адреса на каждом
перенаправлении, формат и размер файла. Технические ошибки не содержат ссылок,
названий файлов или ключей доступа.

Монтаж выполняется на устройстве пользователя через Remotion Player и
Web Renderer. Нужен браузер с WebCodecs и поддержкой кодирования H.264/AAC;
на неподдерживаемом устройстве выводится понятная ошибка. Файлы с устройства
не загружаются на сторонний сервис. Доступ к результатам аккаунта проверяет
существующий API контента. Сцены переходят через короткое затемнение;
длительность сцены управляет обрезкой клипа. Поддерживаются до 20 сцен,
1–30 секунд на сцену, до 120 секунд всего и до 100 МБ на входной файл.

Это встроенный редактор на библиотеке Remotion. Установка плагина ChatGPT
пользователям приложения не нужна. Произвольный React-код от пользователей
не исполняется. В блоке **Монтаж по сценарию** введите промпт и выберите модель.
Кнопка **Смонтировать по сценарию** отправляет обычное текстовое задание Codex;
цена показывается до запуска. Модель использует сценарий, названия и подписи
загруженных материалов. В карточках материалов поле **Описание материала для AI**
позволяет заменить имя файла понятным описанием. Фото и видео не отправляются
модели, их содержимое автоматически не анализируется.

AI выбирает порядок, длительность и подписи сцен, создаёт титры. Полученный
JSON проверяется по ограничениям монтажа и доступным материалам до применения.
Некорректный ответ сохраняется как текстовый результат в истории; текущий
монтаж не меняется. Кнопка **Вернуть монтаж до AI** возвращает предыдущие сцены.
После применения проверьте предпросмотр, поправьте сцены и экспортируйте MP4.
Музыку выбирают отдельно; AI не генерирует голос, музыку или новые видео.

**Прекратить ожидание** прекращает только ожидание в редакторе. Серверное
задание продолжает работу и оплачивается по обычному тарифу; готовность можно
проверить без повторной отправки. Выход из раздела также прекращает ожидание.
Неизвестный статус не приводит к автоматическому повтору платного запроса.
Кнопка **Новый сценарий** начинает отдельное задание по тарифу модели.
Монтаж и входные файлы находятся в памяти раздела; при выходе они освобождаются.
Готовый MP4 скачивается на устройство, автоматически в серверную историю не
добавляется. AI-план использует существующую серверную очередь и списание
кредитов Codex. Предпросмотр и экспорт MP4 не имеют отдельного списания.

Технические сбои передаются через `/api/movie/errors` в ai_logger только как
фиксированные коды, без текста титров, имён файлов, URL, фото или аудио.
Политика CSP HTML веб-приложения допускает чтение локальных `blob:` и
WebAssembly и локальные worker для комплектных аудиокодеков. Внешние соединения и JavaScript eval
не разрешены. Попытки телеметрии библиотеки на внешний домен блокирует CSP.
