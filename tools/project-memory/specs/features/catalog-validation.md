# Каталог, формы и валидация

## Пользовательский список моделей — 2026-10-03

Иконки FLUX, Grok, Ideogram, Recraft и HappyHorse помечены `monochrome` в
`model-catalog.ts`: CSS отображает их светлыми в тёмной теме и тёмными в
светлой. Это применяется в списке групп, строках моделей, кнопке селектора и
крупной иконке выбранной модели в `App.vue`. Recraft использует локальный
`recraft.svg`, поскольку прежний WebP отображал белый квадрат. Цветные логотипы
сохраняют исходные цвета; буквенные заглушки в светлой теме используют
контрастный цвет текста независимо от брендового акцента.

`web/src/components/ModelCatalogPicker.vue` использует `studio.isAdmin` для
отображения провайдерских сведений, включая пользовательский предпросмотр
администратора. Для пользовательского вида описания проходят через
`modelSummary(..., false)` из `web/src/domain/model-catalog.ts`: описания с
Kie/APIMart/RouterAI/Codex или валютными суммами заменяются описанием действия
модели либо нейтральным текстом. В строках не рендерятся провайдерские тарифы,
текущая цена и название поставщика. Служебные варианты каталогов скрыты.
Группы Codex, APIMart и RouterAI отображаются как OpenAI или «Другие»;
семейства моделей (Veo, Kling и др.) сохраняются. Поиск использует те же
пользовательские описания и группы. Исходные ID, маршруты, избранное и цена
кнопки генерации сохраняются; администраторский вид отображает прежние данные.
Проверка: `BROWSER_E2E_MODEL_ACCESS_ONLY=1` в `test/browser-e2e.cjs`.

Для ручной проверки цен и доступности через UI используй
[контракт аудита без генераций](model-ui-audit.md). Он определяет покрытие,
классификацию результатов и восстановление черновиков; наличие модели в каталоге
и успешный quote не подтверждают исполнение генерации.

## Kling 3.0 Motion Control — разрешение — 2026-10-01

Сырой импорт `kling-3.0/motion-control` описывает `mode` только как string с
текстовым соответствием std=720p, pro=1080p, поэтому общая видеопанель не могла
распознать его как разрешение. `catalog-overrides.js` оставляет сырой
`kie-models.json` неизменным, но в эффективном каталоге делает `mode` селектором
720p/1080p с default 720p. Эффективная API-схема принимает также прежние
совместимые значения std/pro, а `pricingAliases` сопоставляет обе формы с
тарифами 720P/1080P. Длительность модели не показывается: она определяется
исходным видео и отдельного параметра duration в схеме нет.

Основание: [Kie Playground](https://kie.ai/kling-3-motion-control) и описание
импортированной схемы `motion-control-v3.md`, проверенные 2026-10-01.
Проверки: `test/catalog.test.js`, `test/video-settings.test.js`.

APIMart использует для Kling 2.6/3.0 Motion Control обязательный `mode=std|pro`.
`providers/apimart/catalog.js` не меняет wire-options, а добавляет presentation
metadata: поле распознаётся основной видеопанелью как качество/разрешение,
показывает только разрешения 720p и 1080p и получает фактический default
std. Сырые `apimart-schemas.json` остаются неизменными. Те же подписи применяются
в web advanced controls и Telegram; в запрос по-прежнему попадают std/pro.

Автоматические адаптеры используют `media/kling-motion-control.js` для
model-specific преобразования mode: Kie 720p/1080p ↔ APIMart std/pro, включая
обе версии 2.6/3.0. Неизвестные значения не заменяются default и проходят
обычную проверку enum; другие модели не затронуты. cost-router сохраняет
prepared-запрос котировки для последующей отправки. Проверки:
`test/kling-motion-control-routing.test.js`, `test/cost-router.test.js`.
Полная доступность маршрута отдельно зависит от переноса исходного видео и
подтверждённой длительности для посекундной котировки APIMart.

## Suno separate-vocals — 2026-10-01

`catalog-overrides.js` исправляет только эффективную схему
`ai-music-api/separate-vocals`: готовая дорожка требует task_id+audio_id,
загруженное аудио требует audio_url и запрещает оба ID. У uploaded-ветки
удалены противоречивое required audio_id и запрещённый контрол audio_id.
stem_name удалён из безусловного required и требуется через allOf/if/then
только при type=split_stem_advanced. Enum и API wire-ключи сохранены,
сырой kie-models.json не переписывается, повторный импорт сохраняет поправку.
requiredUiPaths учитывает then/else и required без локальных properties,
поэтому условно необходимый stem_name доступен пользователю.
Контролы if.properties, управляющие обязательностью then/else, остаются
видимыми с uiVisibleReason=required-condition-control: тип разделения нельзя
скрыть, иначе пользователь не сможет выбрать advanced. Это не добавляет
безусловного required и не меняет API-default.
unionFields читает const-предикаты root allOf из той же схемы и текущего mediaInput;
Composer обновляет обязательность при выборе типа без дублирования правила.
Администратор сохраняет доступ, оба ID готового трека видны и пользователю.

Основание: [текущая OpenAPI](https://docs.kie.ai/suno-api/separate-vocals.md),
[старая OpenAPI](https://docs.kie.ai/old-model/suno-api/separate-vocals.md),
публичный JS [Playground](https://kie.ai/suno-api), проверенные 2026-10-01.
Обе схемы противоречивы; Playground требует и отправляет stemName только
для advanced, а audioUrl исключает audioId. Playground использует старый
/api/v1/vocal-removal/generate, проект сохраняет /api/v1/jobs/createTask.
Это обоснованная совместимая поправка; работа нового endpoint не доказана
платным запросом. Проверки: catalog.test.js, model-ui-visibility.test.js,
browser-e2e.cjs (Suno без отправки генерации).

## Видимость параметров Kie/APIMart по ролям — 2026-10-01

Данные листа «Параметры UI» книги `model-parameter-correspondence-ru-ui-cleaned.xlsx`
сохранены в `config/model-ui-parameters.json`: 173 строки, исходный SHA-256.
Явная поправка владельца: применять разрешения отдельно по колонкам Kie/APIMart,
не объединять через «Наш параметр». «Модели» — примеры, не scope-фильтр.
`src/model-ui-visibility.js` клонирует описание модели и ставит отсутствующим
полям/свойствам `uiHidden: true`, `uiHiddenReason: absent-from-ui-parameter-table`.
Обход сохраняет пути `name[].child`, oneOf/anyOf/allOf и синтетический `__input`.
Маркеры не удаляют свойства, defaults, required или API wire-ключи. Kie применяет
политику после overrides; APIMart — после describeModel, не мутируя общие schemas.
Другие поставщики возвращаются без изменений.

Следующая поправка владельца: исключить из скрытых обязательные параметры.
requiredUiPaths собирает требования fields.required, properties/required и
альтернативных веток, а также пути родительских контейнеров. Отсутствующие в
таблице обязательные поля получают uiVisibleReason=required-for-generation,
их необязательные контейнеры — required-child-container, вместо uiHidden.
Это исключение конкретной модели/пути: например, обязательный Suno title виден,
а необязательный title другой модели остаётся скрытым. Табличный манифест не меняется.
Возвращены 9 корневых ключей (24 пары модель/ключ, включая отдельные режимы)
и 4 вложенных пути (12 пар), вместе с multi_prompt/color_palette контейнерами.
Обязательность внутри необязательной структуры не включает эту структуру сама.

Composer фильтрует только отображаемые поля при `!studio.isAdmin`. Администратор
видит всё с пометками; его пользовательский preview применяет фильтр. SchemaField
наследует showHidden рекурсивно; unionFields копирует маркеры выбранной ветки
и объединяет общие свойства/required корневой схемы с выбранным режимом Suno.
APIMart raw JSON fallback доступен только админу. Полный currentFields обеспечивает
defaults, черновики, валидацию и API-запросы. Не создаются фиктивные обязательные
значения: обязательные поля видны и проверяются обычным способом,
проверки API не ослабляются. SourceAttachments получает отдельно видимые fields
и полный inputFields: смена роли не запускает очистку скрытых исходников, их
значения и sourceFiles сохраняются, пользовательские превью отфильтрованы.
Параметры, открытые по обязательности, также сохраняют ранее заданные URLs.
Legacy standalone-клиент без ролей сохраняет все поля.
Telegram получает роль из доверенного accountFor, фильтрует меню/preview/исходники,
но не изменяет сохранённый input или контракт ручных `/set` и `/params`.
Проверки: `test/model-ui-visibility.test.js`, `test/catalog.test.js`,
`BROWSER_E2E_OMNIHUMAN_ONLY=1` проверяют обоих поставщиков, обе роли,
вложенные поля, сохранение контрактов/defaults и восстановление черновиков.

## Сверка баг-листа моделей — 2026-09-27

Баг-лист `ai_media_model_bugs.xlsx` содержит 82 наблюдения: 27 о цене, 30 о загрузке исходников, 19 о форме/обязательных полях и 6 о ссылке на предыдущую задачу. Наблюдения были сделаны без платных генераций; они указывают на дефекты формы, но не подтверждают успешность запроса у Kie. Все 82 ID присутствуют в эффективном каталоге.

Web-форма обрабатывает `oneOf`/`anyOf` как явный выбор режима с полями выбранной ветки, а массивы и объекты — как структурированный ввод, включая загрузку вложенных изображений. Файлы верхнего уровня связываются с ключом каталога; исправлены импортированные пробелы в ключах HappyHorse и Seedance 2 Fast, поле `image` Recraft и тип `reference_image` HappyHorse. Проверка обязательности и формы вложенных полей выполняется до отправки. Для моделей без текстового промпта он не требуется. Состояние полей и исходников сохраняется по выбранной модели/режиму в черновике.

Публичная история скрывает ID задачи провайдера. Для моделей с `task_id` форма предлагает совместимые успешные записи текущего аккаунта; пользователь может также ввести ID Kie вручную. При отправке сервер заменяет ID выбранной локальной записи на внутренний ID Kie после проверки модели, состояния и аккаунта. `audio_id` обозначает отдельную дорожку Suno, а не задачу.

Цель: новые модели подключаются декларативными полями, различия API локализуются в адаптерах. Актор — пользователь формы; предусловие — выбранная запись каталога.

## Состав и поток

src/catalog.js объединяет kie-models.json, kie-special.json и ручную модель, если её нет в импорте, затем применяет catalog-overrides.js. На 2026-09-21 получено 176 записей: 59 image, 90 video и 27 audio, один провайдер Kie. Это число записей/вариантов, не число проверенных живыми запросами моделей.

Renderer строит поля по описанию: обычные значения, выбор, флаги, файлы, вложенные списки/объекты и альтернативы входа. structured-fields.js отвечает за повторяемые структуры. duration.js вычисляет допустимые длительности и специальные auto-значения; его контракт используется интерфейсом и главным процессом. Override-слой добавляет этот allow-list в поле каталога, когда импортированная схема оставила диапазон только в описании: web/desktop показывают выбор из тех же значений, которые принимает сервер. Недопустимое сохранённое значение черновика/пресета заменяется каталоговым default, а не отправляется скрыто.

Для файловых video/audio-полей web-студия извлекает описанный в каталоге диапазон длительности и читает metadata локального файла до загрузки. Восстановленный локальный источник без сохранённой длительности проверяется через account-scoped preview URL перед отправкой. Выход за диапазон блокирует запуск до Kie и показывает имя файла, фактическую длительность и допустимый интервал; приложение не обрезает пользовательский исходник молча.

Новая web-студия показывает модели не нативным длинным select, а каталогом: поиск сверху, семейства/разработчики слева, модели выбранной группы справа. В строке модели видны локально сохранённый реальный бренд-логотип (WebP, для редких семейств SVG-fallback), краткое назначение и стоимость текущей выбранной конфигурации, когда расчёт уже получен. Поиск работает по модели, описанию и названию семейства; выбранный catalog id остаётся прежним источником данных для черновика, расчёта и генерации. Нативный select сохраняется только как скрытый совместимый элемент для автоматизации и не участвует в видимом интерфейсе.

Перед постановкой и перед отправкой: duration.validate -> AJV inputSchema (если есть) -> buildRequest. AJV настроен strict=false, validateFormats=false. Отсутствие ошибки схемы не доказывает семантическую допустимость у провайдера.

`pnpm check:kie-catalog` проверяет все эффективные записи Kie без сети и платных вызовов: уникальность идентификаторов, официальный источник, компиляцию схем, соответствие полей, типов default/options и enum. Четыре модели с `oneOf`/`anyOf` используют структурированный ввод `__input`; для них проверяются компиляция схемы и наличие этого поля. Проверка не доказывает актуальность импортированной схемы относительно живой документации и не извлекает межполевые ограничения из текста. Для Sounds необязательный `sound_tempo` без выбора пользователя опускается: `null` не соответствует целочисленному типу Kie. `sound_key` допускает документированный default `Any`, отсутствующий в перечислении импортированной схемы.

## Правила адаптеров

- Market: тело {model: apiModel, input}.
- Veo: generationType из режима; firstFrame/lastFrame преобразуются в упорядоченный imageUrls и удаляются из тела; текстовый режим удаляет imageUrls.
- Runway: 10 секунд не сочетаются с 1080p; без imageUrl требуется aspectRatio.
- Flux: при inputImage safetyTolerance не выше 2.
- 4o: нужен непустой prompt или filesUrl.
- Wan 3.0: кадры несовместимы с референсами, документ и ссылки референсов взаимоисключающие; длительность -1 либо целое 2–30.
- Kling 3.0: для multi_shots нужны сцены и не более одного кадра; в одиночном режиме нужен prompt; имена персонажей уникальны, конец фрагмента позже начала.

normalizeTask преобразует специальные статусы, URL и прогресс к общему формату истории. Неизвестный статус — ошибка, а не фиктивный успех. Определение единиц costTime эвристическое: сопоставление с createTime/completeTime, иначе порог 1000.

## Обновление и проверка

Общее меню моделей с ценой (`web/src/domain/auto-models.ts`) скрывает записи,
у которых ни один провайдер не присутствует в подключённом каталоге нужного
типа с опубликованным тарифом. Правило действует для text/image/video/audio
и обеих вкладок списка. При отсутствии Kie сохраняется доступный маршрут
APIMart с ценой. Реестр маршрутов сохраняется: отсутствие модели в текущем
каталоге не удаляет её ID, историю или тарифы из общей БД. Наличие модели
в каталоге не подтверждает успешность платной генерации. Проверка:
`test/service-models.test.js`.

Импорт: scripts/import-kie.js, import-special.js, import-missing.js; ручные исправления сохраняются отдельным override-слоем. kie-import-report.json относится к сырому импорту и не описывает итоговую полноту каталога.

Источники: src/catalog.js, catalog-overrides.js, adapters.js, duration.js, structured-fields.js.
Проверки: test/catalog.test.js, adapters.test.js, overrides.test.js, ui-smoke.cjs. Проверять уникальность ID, компиляцию схем, порядок кадров, типы запросов, каталоговые варианты длительности и построение форм. Размер исходного видео и суммарная длительность нескольких файлов по-прежнему не проверяются по медиаметаданным; проверяется индивидуальная длительность там, где диапазон однозначно извлекается из описания поля.

## Основные параметры видео — 2026-09-30

`web/src/domain/video-settings.ts` выбирает из каталога поля пропорций,
разрешения/качества и длительности без зависимости от порядка. Только выбранные
поля исключаются из дополнительных; альтернативное качество, режим и прочие
параметры сохраняются. `VideoSettingsBar.vue` выводит модель и эти три группы
с подписями сверху и общей шестерёнкой, открывающей остальные поля, включая JSON.
Группы пропорций и разрешения/качества отображаются только при наличии поля
в эффективном каталоге; пустой контрол с прочерком не выводится. В частности,
Kling 2.5 Turbo Text to Video Pro не поддерживает выбор разрешения.
Поля и шестерёнка имеют высоту 34 px. Блок и кнопка генерации всегда остаются
в одной строке; при недостаточной ширине контейнера используется горизонтальная
прокрутка. Flex-компоновка сохраняет естественную ширину названия модели и select;
длительность выводится компактным `DurationPicker.vue` вместо ползунка/native select.
Меню вынесено в body, позиционируется у кнопки, прокручивается со скрытой полосой,
имеет стрелки прокрутки только при переполнении списка, выбор с клавиатуры
и отметку выбранного значения. Высота короткого меню определяется вариантами
без пустого места под стрелки; переполнение учитывает доступную высоту окна.
Кнопка модели имеет минимум 168 px и шрифт 14 px; полоса горизонтального ряда скрыта.
Списки пропорций и разрешения содержат только значения каталога, без пункта
«По умолчанию»; их ширина определяется содержимым без фиксированных 78/82 px.
Кнопка пресетов скрыта. Вместо неё каталог моделей содержит звёздочку у каждой
модели и раздел «Избранное» для текущего провайдера и режима. Выбор звёздочки
сохраняет только модель, не выбирает её и не закрывает каталог. Избранное хранится
в account-scoped preferences (`model-favorites`) через `getModelFavorites` /
`setModelFavorites`: ключ `provider:mode:modelId`, максимум 500 записей.
В автоматическом каталоге provider-часть ключа равна `auto`, чтобы смена
маршрута Kie/APIMart не меняла отметку. Одинаковые ID разных провайдеров/режимов независимы; переключение каталогов
фильтрует видимые модели, но не удаляет сохранённые отметки. При наличии избранных
каталог открывает этот раздел; поиск внутри него ограничен избранными моделями.
Ошибка загрузки допускает повтор, до успешной загрузки запись запрещена;
ошибка сохранения оставляет прежние отметки. Пресеты и их данные сохраняются.
Кнопка генерации использует шрифт 16 px, сохраняя высоту 34 px и общий ряд
с параметрами видео.
`Composer.vue` сохраняет прежние обработчики, черновики, валидацию и расчёт цены.
Предупреждение Kie при `quote.status=unavailable` скрыто в пользовательском
представлении и сохранено для `studio.isAdmin`. Ошибки расчёта и запуск задач
сохраняют прежнее поведение; переключение admin → user скрывает предупреждение.

Меню длительности сохраняет wire-значения enum и отображает секунды. «Авто»,
нулевые и отрицательные варианты скрываются только в UI; сохранённое автоматическое
значение заменяется доступным default модели или первым конкретным вариантом.
`videoDurationOptions` берёт готовый enum,
либо перечисляет ограниченный диапазон min/max или schema minimum/maximum
с фиксированным шагом (по умолчанию 1). Непрерывный диапазон с step=any и
слишком большой список не перечисляются: сохраняется обычный ввод.
Allow-list и специальные значения (-1/0) приходят из эффективного каталога:
описания диапазонов по-прежнему обрабатывает общий `src/duration.js` через
`src/catalog-overrides.js`; UI не дублирует правила моделей. Без диапазона остаётся обычный ввод;
без самого поля показывается прочерк. Параметры num_frames не выдаются за секунды.
При смене модели/провайдера/вкладки дополнительные настройки закрываются.
Контракт проверяется `test/video-settings.test.js` на свежем контейнере тестов.
