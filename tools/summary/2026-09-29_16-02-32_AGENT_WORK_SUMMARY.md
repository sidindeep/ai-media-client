## Thematic Thread Breakdown

### Сопоставление моделей

- Пользователь заметил повторяющиеся Seedream-модели из двух провайдеров и потребовал таблицу для *всех* моделей APIMart и Kie, включая Claude, DeepSeek, Gemini и GPT, а не только моделей изображения.
- Для каждого действия модели (например, Text to Image и Edit) решено сохранять отдельную строку. Пользователь прямо назвал это временным выбором: после тестирования может понадобиться объединять действия.
- Таблица в `docs/model-correspondence.md` связывает ID APIMart, ID Kie и отображаемое имя сервиса. Excel сохранён отдельно: `data/service/exports/model-correspondence-v1-v2.xlsx`; рядом есть исходные выгрузки `model-correspondence.xlsx` и `model-correspondence-501.xlsx`. Markdown оставлен.

### Версии каталога и меню

- `config/service-models.json` содержит 501 строку полного снимка (271 строка с Kie ID и 336 строк с APIMart ID; один APIMart ID может повторяться для разных действий Kie). `config/service-models-v2.json` содержит 106 строк с обоими ID; обе версии имеют исходный снимок от 2026-09-29T12:47:35.134Z.
- Версии хранятся в PostgreSQL `media_service_model_configs`: одна глобально текущая, альтернативные доступны по авторизованному API. По последней проверке текущая версия — полная V1, V2 неактивна. Переключение в студии меняет только локальную форму, а не глобальную текущую запись.
- В `web/src/components/ModelCatalogPicker.vue` и `Composer.vue` вместо маленького отдельного select появились две вкладки внутри выбора моделей. V2 показывает только общие строки. Если для режима в V2 нет моделей, меню остаётся открываемым для возврата в V1. Есть состояния загрузки и ошибки переключения.

## Topic Theses

- **Имя не равно маршруту:** совпадение ID в таблице и наличие строки V2 сами по себе не подтверждают совместимость параметров и наличие работающего API-адаптера у обоих провайдеров. Ценовое автосравнение ограничено `config/cost-routing-compatibility.json` и каталогами реально доступных моделей.
- **Модели без пары не исчезают:** V1 сохраняет их отдельными строками. V2 фильтрует по наличию обоих ID, сохраняя раздельные действия.
- **Источник списка:** Kie marketplace снимок в `config/kie-market-models.json` включает опубликованные пути, часть которых ещё не подключена к генерации в приложении.
