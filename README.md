# AI Media Client

## Windows без установки

После сборки запустите `dist/queue-header/win-unpacked/AI Media Client.exe`.
Копируйте папку целиком — библиотеки и `resources` нужны для запуска.
История и зашифрованные ключи хранятся в профиле Windows, а не рядом с EXE.
Сборка папки: `pnpm pack`. Каталог `dist/queue-header` не хранится в Git.

Расширяемый Windows-клиент для генерации изображений и видео через внешние API.

## Первый этап

- провайдер Kie.ai;
- Grok Imagine Video 1.5 Preview;
- динамическая форма из описания модели;
- локальная загрузка до 7 референсов;
- запуск и автоматическое отслеживание задачи;
- просмотр результата, баланса и фактически списанных credits;
- API-ключ шифруется через Windows DPAPI (`Electron safeStorage`).

Архитектура специально разделяет провайдера и модель. Новый сайт добавляется как адаптер API, а новая модель — декларативным описанием полей. Поэтому начальный/конечный кадр, одиночное изображение или набор референсов отображаются только у моделей, которые их поддерживают.

## Запуск

```powershell
pnpm install --frozen-lockfile
pnpm start
```

Проверка перед коммитом: `pnpm check` и `pnpm test`. Для теста интерфейса
используйте `pnpm exec electron test/ui-smoke.cjs`.

Сборка установщика Windows:

```powershell
pnpm dist
```

## Следующие этапы

История уже сохраняется в `history.json` в папке данных приложения Windows.
Доступны поиск по промпту/провайдеру/модели, просмотр результатов по ссылке,
восстановление настроек и продолжение проверки задачи после перезапуска.
Файлы можно скачать из истории в выбранную папку. Опциональное автосохранение
скачивает результаты при получении успешного статуса задачи. При закрытом
приложении скачивания не продолжаются; после перезапуска продолжите проверку
задачи из истории. Локальное наличие файлов проверяется при обновлении истории.
Незавершённые загрузки не отмечаются как сохранённые; повторное скачивание
пропускает уже сохранённые файлы. Новые исходники сохраняются в подпапке `sources`
профиля приложения. Повтор восстанавливает файлы и вложенные референсы; перед
каждой генерацией они заново загружаются провайдеру. Старые записи, созданные до
этого обновления, содержат только ссылки и могут требовать выбора исходника.
Неопределённый результат отправки помечается
для проверки в журнале Kie, чтобы случайно не создать платную задачу повторно.
Расход по отдельным задачам и моделям показывается из `creditsConsumed`, если API
его вернул. Дополнительно клиент сверяет суммарный расход со снижением баланса
между контрольными замерами; пополнения и операции вне клиента отражаются как
расхождение. При параллельных задачах баланс не используется для распределения
расхода по моделям.

Проверка сохранения истории: `node --test test/history.test.js`.

1. Дополнить импорт каталога отдельными API и сложными схемами; прайсинг отложен.
2. Дополнительные настройки локального хранения.
3. Интерфейс добавления нового провайдера и SDK адаптеров.
4. Пресеты и пакетное создание запросов.

## Очередь

«Запустить генерацию» сохраняет запрос с выбранными исходниками и сразу запускает
очередь. «Запустить очередь» возобновляет её после паузы. Задачи отправляются по одной. Пока задача выполняется, можно
редактировать форму и добавлять другие. «Пауза» блокирует новые отправки, но
статус уже отправленного задания продолжает проверяться. Ожидающую задачу можно
убрать из очереди; отмена уже оплаченной задачи у провайдера не поддерживается.
После перезапуска очередь приостановлена. При продолжении сначала проверяется
известная удалённая задача. При обрыве ответа на POST автоматической повторной
отправки нет. Кнопка «Пропустить без повторной отправки» позволяет продолжить
очередь после проверки журнала провайдера. Исходники по введённым внешним ссылкам
автоматически не скачиваются; долговечные повторы доступны для локально выбранных файлов.

## Каталог Kie

Каталог содержит 131 импортированное описание Market (55 image / 76 video).
Обновление из публичных OpenAPI: `node scripts/import-kie.js`.
Отчёт исключений Market: `src/kie-import-report.json`. Импорт не означает, что каждая
модель проверена реальным запросом. Дополнительно подключены 12 вариантов отдельных
API: Veo 3.1 (8 сочетаний моделей и режимов), Runway, Flux Kontext Pro/Max и 4o.
Итого 143 записи. Обновление отдельных API: `node scripts/import-special.js`.
У Veo начальный и конечный кадры — отдельные поля, референсы — отдельный режим.
Запуск и получение результатов отдельных API используют свои адреса и преобразуются
в общий формат истории. Пропущенные сложные схемы Market требуют подключения.
Вложенные списки и объекты редактируются через повторяемые блоки: сцены,
персонажи, референсы, цвета и координаты. Есть добавление, удаление и порядок
элементов. Документированные альтернативы входа выбираются в форме.
Четыре дополнительные схемы восстановлены: Kling Omni image/reference-to-video,
PixVerse Extend, Grok Segment Map. Всего 147 записей.
Wan 3.0 / Prime исправлены по публичному Playground: кадры — строки URL,
референсы — массивы ссылок с загрузкой соответствующих файлов. Kling 3.0
подключён по официальным примерам запросов (одна/несколько сцен, персонажи).
Эти исправления находятся в `src/catalog-overrides.js` и сохраняются при
повторном импорте. Всего 148 записей. Отчёт импортера отражает только сырую
OpenAPI-документацию и не учитывает этот слой исправлений.
Проверяются конфликты кадров/референсов Wan, режим сцен Kling и типы параметров.
Ограничения длительности и размеров входного видео из описаний провайдера
пока не проверяются по метаданным файла локально.
Проверка схем: `node --test test/*.test.js`.
Проверка форм в скрытом окне без API: `electron test/ui-smoke.cjs`.
