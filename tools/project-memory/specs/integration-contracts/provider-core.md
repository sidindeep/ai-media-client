# Общий контракт провайдера приложения

Статус 2026-09-28: `src/providers/contract.js` фиксирует минимальный интерфейс;
APIMart подключён к нему для текста, изображений, видео и аудио. Codex теперь
использует `src/providers/codex/application.js` для котировки, отправки и чтения
задания; выдача изображения и восстановление остаются в сервисе биллинга.
Действующий Kie-роут сохраняет свой транспорт и очередь; переход всех роутов на
этот интерфейс ещё не выполнен. Медиа-контракт `src/media/index.mjs` остаётся внутренним слоем для
изображений, видео и аудио, а не вторым реестром поставщиков.

## Обязательные свойства и методы

| Член | Смысл |
| --- | --- |
| `id`, `name`, `kinds` | Стабильный ID, видимое имя и поддерживаемые режимы: text/image/video/audio. |
| `billing.mode`, `billing.unit` | `wallet`: котировка в кредитах приложения; `external`: оплата напрямую поставщику; `subscription`: лимиты подписки. Нулевая цена и неизвестная цена различаются. |
| `listModels()` | Только доступные для конкретного маршрута модели с ID, названием, видом и семантическими полями. Каталог не доказывает, что любая модель поддерживает данный endpoint. |
| `quote(request)` | `exact`/`estimated`, `unavailable` или `external`; внешняя оплата возвращает `credits:null`. Полная сумма в валюте/кредитах поставщика хранится отдельно. |
| `submit(account, request)` | Одна отправка с пользовательским `requestId`; неопределённый исход не запускает автоматический повтор. |
| `getTask(account, requestId)` | Чтение своего сохранённого задания без нового запуска. |
| `getStatus()` | Настроенность, остаток с явной единицей либо `null`, лимитные окна при наличии. Отсутствие API баланса не превращается в ноль. |
| `supportsUpload`, `uploadAsset()` | Дополнительная возможность для маршрутов с исходными файлами; загрузка не требуется для текстовых моделей. |

Приложение владеет доступом по ролям, кошельком, историей, файлами и повторным
опросом. Адаптер скрывает ключи и формат HTTP-ответов поставщика. Модель
описывает разработчика отдельно от поставщика: Kie/RouterAI/APIMart — поставщики,
OpenAI/Google/Anthropic и другие — группы моделей. Нельзя группировать весь
каталог агрегатора под одним разработчиком.

## Калибровка по текущим роутам

| Роут | Каталог | Запуск и чтение | Стоимость | Статус |
| --- | --- | --- | --- | --- |
| Kie | локальный каталог и схемы параметров | `create`, `poll`, загрузка | котировка в кредитах приложения; остаток Kie — отдельная единица | баланс Kie |
| RouterAI | API-каталог, отбор по режиму | текст/медиа, отдельный маршрут видео | конвертер в кредиты приложения | остаток в рублях |
| Codex | доступный CLI-каталог | текст/изображение | фиксированная продуктовая котировка | лимитные окна, без баланса |
| APIMart | полный API-каталог + схемы конкретных моделей | текстовые API, медиа-задачи с сохранённым ID, TTS и распознавание | внешняя оплата; оценка полной генерации; `cost`/`credits_cost` задачи — фактический расход | `/v1/user/balance` — остаток аккаунта |

Ответ `POST /v1/chat/completions` документирует `usage` в токенах, без суммы
списания. `GET /v1/usage` возвращает `data.total.amount_usd` и
`data.total.credits` за интервал, с фильтром модели и группировкой по модели/дню;
это не цена по ID запроса. Показатель может запаздывать и кешироваться, поэтому
разность остатков до/после не является надёжной ценой при параллельных вызовах.
Документация упоминает `POST /v1/logs/export` для детализации вызовов, но его
контракт получения записи и сопоставления с нашим requestId пока не проверен.

Следующий переход выполняется по одному маршруту: адаптер реализует контракт,
общие UI/серверные вызовы переключаются на него, проверяются сохранение
черновика, идемпотентность, цена и состояния сбоя. Не выдумывать цену APIMart
из токенов без проверенного тарифа и курса.
