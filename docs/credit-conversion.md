# Конвертация цен роутеров в кредиты

Пользователь видит и оплачивает генерации внутренними кредитами. Номинал одного
кредита — 1 ₽ цены услуги; фактическая цена приобретения кредита зависит от
пакета. Сервер получает исходный тариф провайдера, рассчитывает стоимость
конкретного запроса и возвращает ценовую котировку в минимальных единицах:
1000 единиц = 1 кредит.

`src/billing/conversion/` содержит общий расчёт и адаптеры. Кредит Kie
временно равен одному кредиту сервиса; закупочная стоимость Kie в другой
единице используется только для сравнения маршрутов. APIMart также
резервирует и списывает кредиты сервиса 1:1 к своим кредитам. RouterAI передаёт рублёвую цену запроса. Для Codex
нет достоверной себестоимости конкретного запроса: адаптер сохраняет
фиксированную продуктовую цену из `config/native-prices.json`.

Общая политика хранится в `config/credit-conversion.json`. Нижняя граница цены:

```text
себестоимость_₽ × (1 + наценка_к_себестоимости)
──────────────────────────────────────────────────
минимальная_цена_покупки_кредита_₽ × (1 − удержания)
```

Минимальная цена покупки вычисляется из активных рублёвых пакетов
`config/product-offers.json`. Расчёт по этой формуле применяется к RouterAI;
Kie и APIMart временно используют соответствие кредитов 1:1. Результат округляется вверх до
0,001 кредита. Доли удержаний и наценка пока взяты из рабочей финансовой
модели; их нужно пересмотреть перед коммерческой публикацией.

Новый роутер подключает адаптер, который возвращает `costAmount`,
`costCurrency`, `rawVersion` и при необходимости `nominalCredits`. Для
иностранной валюты нужно передать версионированный курс `rubPerUnit` с
`validUntil`; устаревший или отсутствующий курс блокирует расчёт. Источник
курсов и период их обновления выбираются при подключении такого роутера.
Котировка включает версию исходного прайса, курса и политики, фиксируется
при резервировании; последующее изменение тарифов не пересчитывает задачу.
Пользовательский API возвращает только итог в кредитах.

Администратор видит действующие ставки, пакеты, примеры пересчёта по роутерам
и подключённые валютные курсы на вкладке «Конвертер кредитов» в `/admin.html`.
Данные читаются из текущего серверного конвертера через защищённый
`GET /api/admin/credit-conversion`; это обзор, без изменения политики из браузера.
