# Стоимость и сверка расходов

Цель: отделить прогноз от фактического списания, не выдавать неизвестное за ноль. Источники: src/costs.js, tariffs.js, kie-session.js, price-audit.js, main.js.

## Факт и рубли

amount принимает конечное неотрицательное число либо десятичную строку. Пустое/некорректное => null; ноль допустим. Факт берётся только из creditsConsumed. На постановке задачи сохраняется rubPerCredit; charge использует этот курс, а для старых записей — текущий с признаком отсутствия исторического курса. Значение по умолчанию 0.51; настройка должна быть >0 и <=100000.

Суммы округляются до сотых. Дедупликация по providerId + (taskId или локальный id). День/месяц отбираются по локальной дате createdAt. Неизвестные суммы учитываются отдельно для success, fail, unknown, unconfirmed. Оценка не подставляется вместо факта.

## Оценка

### RouterAI — 2026-09-23

Исходная цена RouterAI выражена в рублях; модуль
`src/billing/conversion/` переводит её в продуктовые кредиты по общей политике.
`MEDIA_RUB_PER_CREDIT` относится к себестоимости кредитов Kie. Источник цены —
публичный `GET /api/v1/models` RouterAI, кэш 10 минут; перед платной отправкой
тариф обновляется. Итог округляется вверх до 0,001 кредита. Посекундное видео использует явно
передаваемую длительность и базовое разрешение; варианты разрешения, которые
API не оценивает отдельно, не получают точной цены. Тарифы с неизвестным заранее числом
токенов или иной переменной единицей также не получают фиктивный fallback
4 кредита. Точная quote резервируется и затем списывается или освобождается
по общему контракту кошелька. `usage.cost` провайдера сохраняется для аудита,
но не пересчитывает уже принятую цену. Старые задачи не переоцениваются.

При постановке сначала запрашивается оценка аккаунта Kie; при отсутствии/ошибке используется локальный тариф. KieSession очищает prompt/description и заменяет медиа-значения маркерами наличия по именам полей; это эвристическая редукция, не универсальная гарантия удаления любых чувствительных полей. Кэш оценки 5 минут.

Локальная quote поддерживает конкретные режимы Grok, Kling, Veo, Hailuo, Seedance, Imagen, Seedream. Требуется ровно одно совпадение описания тарифа без учёта регистра и точное совпадение единиц. Цена за секунду умножается на длительность; per video/image/request не экстраполируется произвольно. Неподдерживаемое сочетание => null.

Tariffs получает публичные страницы по 100 записей без пользовательского API-ключа; предел 30 страниц, таймаут страницы 15 секунд. Кэш 24 часа, одновременные обновления объединяются. При ошибке возвращается старый кэш или пустые строки с stale/error.

## Сверка

baseline и current содержат balance и сумму известных apiCredits. balanceSpent = baseline.balance - current.balance; apiSpent = current.apiCredits - baseline.apiCredits; difference = balanceSpent - apiSpent. Разница может отражать пополнение или внешние операции. Её нельзя распределять по моделям как доказанный расход.

## Аудит цен

plan строит базовый вход каждой Kie-модели и меняет по одному параметру цены, устраняя дубли по стабильному ключу. Это не полный декартов перебор сочетаний. compare: обе цены отличаются менее чем на 0.01 => match, иначе mismatch; только аккаунт => confirmed, только тариф => tariff-only, ни одной => unavailable.

Проверки: test/costs.test.js, tariffs.test.js, price-audit.test.js, kie-session.test.js. Эти автоматические тесты не проверяют реальную цену и доступность endpoint; отдельная живая проверка ByteDance V1 зафиксирована ниже. Нельзя обещать полноту тарифов по всему каталогу.

## Проверка ByteDance Seedance V1 — 2026-09-22

Живой публичный `POST https://api.kie.ai/client/v1/model-pricing/page`
вернул 486 тарифных строк на пяти страницах, но не вернул ни одной строки для
пяти доступных в каталоге моделей `bytedance/v1-*`: Lite image/text-to-video,
Pro image/text-to-video и Pro Fast image-to-video. Поэтому текущий серверный
`quoteKie` штатно отвечает «Цена этой модели Kie ещё не опубликована»: он
доверяет только этому тарифному API и не использует маркетинговые страницы.

На официальной странице `https://kie.ai/bytedance/seedance-v1` цены при этом
опубликованы в структурированном `pricingDesc`: Lite — 2 / 4.5 / 10 кредитов за
секунду для 480p / 720p / 1080p; Pro — 2.8 / 6 / 14 кредитов за секунду;
Pro Fast — 16 / 36 кредитов для 5 / 10 секунд в 720p и 36 / 72 кредита для
5 / 10 секунд в 1080p. Это подтверждает рассинхронизацию официальных источников,
а не невозможность математического расчёта.

По решению пользователя добавлен серверный версионированный fallback
`config/kie-price-fallbacks.json`. Он содержит только точные сочетания
model/resolution/duration из официального `pricingDesc`, не публикуется как
клиентский источник и применяется лишь когда live-каталог не вернул ни одной
строки выбранной модели. Любая появившаяся live-строка модели имеет приоритет;
неизвестная fallback-комбинация остаётся без точной цены. Версия расчёта явно
отличает `kie-page-2026-09-22-seedance-v1` от `kie-live-*`. Тесты фиксируют
значения пяти моделей, отказ для неизвестных параметров и приоритет live API.

## Сопоставление версий модели в URL Kie

У некоторых live-тарифов Kie имя версии в API-модели и в URL страницы записано
по-разному: `bytedance/seedance-1.5-pro` опубликована под
`https://kie.ai/seedance-1-5-pro`. Для коротких path-only URL сопоставление
считает точки, подчёркивания и дефисы эквивалентными, сохраняя остальные символы.
Явный параметр `?model=` остаётся авторитетным и требует точного совпадения —
нормализация не должна позволять тарифу одной модели примениться к другой.

Проверенный режим Seedance 1.5 Pro: 720p, 4 секунды, без аудио — 3,5 кредита
за секунду, итого 14 кредитов; с аудио — 7 кредитов за секунду, итого 28.

## Сопоставление тарифов после изменения ссылок Kie — 2026-09-23

У Grok Imagine Video 1.5 Preview официальный тарифный API возвращает строки с
точным `modelDescription`-префиксом `grok-imagine-video-1-5-preview`, но ссылка
ведёт на `/grok-imagine-video-1.5`, а API-модель содержит суффикс `-preview`.
После точного совпадения `?model=` расчёт может сопоставлять такой префикс
описания с API ID модели, только если ссылка не содержит другого явного
`?model=`. Совпадение по короткому пути остаётся последним вариантом.
Опубликованные цены: 480p — 2,4 кредита/сек., 720p — 4,5 кредита/сек.;
8 секунд стоят соответственно 19,2 и 36 кредитов. Неподтверждённый 1080p
остаётся без точной цены. Источники: публичный `model-pricing/page` и
`https://kie.ai/grok-imagine-video-1.5`.

Выбор строки учитывает `rendering_speed` Ideogram как вариант скорости и
документированное соответствие `quality=basic/high` Seedream 5 Pro разрешению
1K/2K. Поля `image_size` и `image_resolution` не означают наличие исходного
изображения; режим image-to-image выбирается только при медиа-поле ссылки или
файла. Источник соответствия качества:
`https://kie.ai/seedream-5-0-pro`. Ошибочный предварительный расчёт с
отсутствующей ценой не обещает успешный запуск; с 2026-09-24 он показывает
предупреждение и не блокирует кнопку. Временные ошибки чтения прайса также
не останавливают отправку. На границе
платной отправки уже выполненное принудительное обновление прайса не
повторяется второй раз при отсутствии строки.
У `grok-imagine/upscale` разрешение в форме означает выходное разрешение после
стрелки в тарифном описании. Для 720p есть однозначная цена 10 кредитов;
две разные цены 1080p зависят от исходного разрешения, которое текущий запрос
на расчёт не подтверждает, поэтому такой вариант остаётся неопределённым.

У GPT Image 2.5 Flare Kie публикует тарифы по общей странице
`https://kie.ai/gpt-image-2-5` без `?model=`. В начале описания строки идут
имя семейства и режим через запятую (например, `gpt-image-2-5-flare,
image-to-image, 2K`), тогда как API ID объединяет их дефисом. Для ссылок без
явного `?model=` расчёт сопоставляет точную пару имя + режим с API ID. Режимы
text-to-image и image-to-image не смешиваются; при отсутствии разрешения цена
остаётся неопределённой. Проверенный тариф Kie на 2026-09-24: 1K — 6,
2K — 10, 4K — 16 кредитов за изображение.

Для тарифных ссылок Kie без `?model=` возможна запись полного API ID одним
URL-сегментом: `wan/2-7-image` опубликована как `/wan-2-7-image`. После точного
ID и описания расчёт сопоставляет полный ID с таким slug, а затем пробует
короткое имя без пространства имён. Явный `?model=` по-прежнему требует
точного совпадения. В публичном тарифном API Wan 2.7 Image стоит 4,8 кредита
за изображение, Pro — 12; Pro имеет собственный явный `?model=`. Для тарифов
`per image` учитывается поле количества `n`. У обеих моделей Wan 2.7, если `n`
опущено, провайдер выбирает 4 изображения в обычном режиме или 12 при
`enable_sequential=true`; предварительная стоимость использует те же значения.

## Общие стратегии и лимит расхода — 2026-09-24

`src/billing/kie-tariff-resolver.js` выбирает кандидатов строки Kie в порядке
точного `?model=`, описания, полного slug и сокращённого slug. Последний
вариант не перекрывает явно указанный чужой ID.
`src/billing/quote-engine.js` содержит общие формулы для фиксированного запроса,
числа изображений, пакетов изображений, секунд, блоков символов и измеренных
токенов. Адаптеры Kie и RouterAI выбирают проверенную тарифную строку и единицу,
затем используют эти формулы. Сопоставление URL/описания Kie по-прежнему
отдельно от арифметики; неоднозначные строки не превращаются в цену. Результат
расчёта может иметь статус `exact`, `bounded` или `unavailable`; неизвестное
количество токенов до ответа провайдера относится к `unavailable`.

`src/billing/normalize-request.js` закрепляет значения `n` для Wan 2.7 Image
до валидации, хеширования запроса, предварительного расчёта и отправки в Kie.
Исходный объект вызывающего кода не меняется. Для других моделей не следует
молча подставлять значения без подтверждения контракта их API.

Кошелёк может удержать проверенный верхний предел и при успехе списать
`actualAmountUnits` не больше удержанной суммы, освободив остаток в той же
транзакции; повторная сверка не меняет баланс. При неизвестном результате
резерв остаётся удержанным только для задач с известной ценой. По решению
пользователя от 2026-09-24, `unavailable` не запрещает запуск Kie или RouterAI:
интерфейс и Telegram показывают предупреждение, задача отправляется провайдеру,
а кошелёк не создаёт резерв и не списывает продуктовые кредиты. Это касается
моделей с переменной стоимостью токенов и отсутствующих/временно недоступных
тарифов. Известная на границе отправки точная цена сохраняет обычную оплату.
Расход у провайдера всё ещё возможен; `usage.cost` хранится для аудита, но без
проверенного правила конвертации не превращается задним числом в списание.
