## Проверенный контракт

По README, package.json и src/: это приватный ESM-пакет `llm-providers`
версии 0.1.0, Node >=20, без runtime-зависимостей. Реализации находятся в
`src/providers/`, а `templates/` содержит шаблон документации стека.

- Адаптеры: DeepSeek, OpenAI-compatible, LM Studio, Codex app-server,
  Codex CLI, mock. Названия подтверждены экспортами и реестром; реальная
  работоспособность внешних сервисов в этом исследовании не проверялась.
- `loadProviderConfig` нормализует конфигурацию;
  `createProvider` / `generateWithActiveProvider` выбирают адаптер.
- Вход: prompt или messages, model, temperature, maxTokens, output.
- Выход: provider, model, output, parsed, raw.
- Контракт output поддерживает выделение JSON-блока, JSON parsing,
  jsonSchema для поддерживающего адаптера и валидатор вызывающей стороны.
  Сам jsonSchema не означает локальную валидацию результата: её нужно
  задавать через validate (проверено по outputContracts.mjs).
- HTTP-адаптеры используют chat completions; DeepSeek и LM Studio строятся
  на общей реализации. LM Studio нормализует суффикс /v1.
- `bin/llm-provider.mjs` / `providerBridge.mjs` предоставляют JSON stdin-мост.

## Применение в веб-версии

Использовать как одобренный источник серверных LLM-адаптеров, когда определён
пользовательский сценарий LLM. Сценарии написания/перевода промптов пока
не запрошены явно; не считать их согласованными функциями.
Генерация изображений/видео через Kie остаётся отдельным контрактом:
chat-completions адаптеры не заменяют очередь медиа-задач и их опрос.

Конфигурация, секреты и выбор разрешённого провайдера принадлежат серверу;
нельзя напрямую открывать клиенту произвольный config-envelope, URL или
команду локального процесса. Перед переносом HTTP-адаптера добавить границу
таймаута/отмены и безопасные ошибки: в текущем исходнике fetch не получает
signal, а ошибка включает фрагмент тела ответа провайдера. Не отдавать raw
наружу без нужды. Codex-адаптеры зависят от отдельного локального runtime.

Форма подключения (адаптация выбранных файлов либо пакет) пока не выбрана.
Не закреплять машинный абсолютный путь в runtime и не менять текущий
CommonJS-проект целиком ради ESM-пакета. Исходный проект изменять только по
отдельному запросу.
