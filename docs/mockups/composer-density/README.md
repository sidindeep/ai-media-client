# Макеты компактной панели генерации

Сравнение трёх согласованных вариантов находится в [index.html](index.html):

- A — бережное сжатие, пресеты остаются отдельной строкой;
- B — сбалансированный вариант, пресеты собраны в выпадающий контрол;
- C — строка быстрого ввода, вторичные параметры скрыты.

В продукте реализован вариант B. Макеты A и C сохранены для возможной дальнейшей итерации.
