Версия, контрольные суммы, исходники и назначение: manifest.json.

ПРОСМОТР
Открыть index.html напрямую или /app/ui-icons/index.html на запущенном сайте.
Страница автономная: без CDN, внешних шрифтов и запросов к сервисам.
Поиск работает по русскому назначению и имени файла. Доступны светлая/тёмная
темы и размеры 16/20/24 px. Нажатие на карточку скачивает SVG.

ПРАВИЛА СТИЛЯ
Сетка 24×24. Размеры: 16 px для плотных строк, 20 px для обычных кнопок,
24 px для крупных элементов. Толщина линии 1.75 в координатах viewBox.
Линии и соединения скруглены. Цвет currentColor. Без теней и градиентов
внутри иконок. Активное состояние выделять цветом и фоном кнопки.
Подложка и размер области нажатия задаются кнопкой, а не SVG.
Не смешивать в одной группе разные толщины и outline/filled-варианты.
Бренды моделей и провайдеров остаются отдельными логотипами.

ПОДКЛЮЧЕНИЕ
Это подготовленный набор; существующие экраны ещё не переведены на него.
SVG можно вставлять inline в Vue: цвет тогда наследуется от кнопки.
Для декоративной SVG рядом с текстом: aria-hidden="true" focusable="false".
Для кнопки без текста обязательно задать доступное имя через aria-label.
При использовании <img> задавать alt; currentColor не наследует цвет
родительского HTML, поэтому для окрашиваемых иконок использовать inline SVG.
Соблюдать prefers-reduced-motion при анимации индикатора загрузки.
Исходники находятся в web/public/ui-icons; Vite копирует их при сборке.
Не редактировать сгенерированные копии public/vue/ui-icons.
