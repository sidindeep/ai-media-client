# Локализация веб-интерфейса

## Цель и границы

Модуль `web/src/i18n/` — единый источник локализованной статики Vue-сайта: подписей,
состояний, ошибок, accessibility-атрибутов, лендинга и форматов дат/чисел. Промпты
пользователя, промпты-подсказки и текст, вернувшийся от модели/провайдера, не переводятся.

## Контракт

- Локали имеют BCP 47-коды `ru` и `en`; `rus` и `eng` принимаются только как входные алиасы.
- `ru.ts` задаёт `TranslationKey`; `en.ts` компиляционно обязан содержать те же ключи.
- `t(key, params)` выполняет интерполяцию `{name}`; `tp(key, count)` выбирает форму числа через
  `Intl.PluralRules` и ветки `.one/.few/.many/.other`.
- Числа и даты форматируются через `formatNumber` и `formatDate`, а не через зашитый `ru-RU`.
- Выбор хранится в `localStorage` под ключом `ai-media-client.locale`; при первом запуске учитывается
  язык браузера, затем применяется русский fallback.
- При смене локали обновляются реактивный UI, `document.documentElement.lang` и статические узлы лендинга с
  `data-i18n*`.
- Новая статика не должна появляться напрямую в Vue-шаблонах; для неё добавляется namespace-ключ в оба словаря.

## Проверка

- `pnpm check:web:vue` подтверждает типы ключей и паритет словарей.
- `test/localization.test.js` проверяет паритет ключей и ссылки `data-i18n*` лендинга.
- Финальная проверка выполняется только на свежей Compose-сборке с проверкой `/api/health`.
