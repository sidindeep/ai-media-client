# Согласование каталога и меню моделей

Единственная рабочая таблица — `media_model_routes` в общей PostgreSQL.
Каталог Kie собирается из локальных схем и override-слоя; APIMart получает
полный список через свой API. Таблица хранит стабильные ID проекта, действия,
подтверждённые соответствия провайдеров и опубликованные тарифы.

`src/services/model-route-sync.js` согласует эти источники при чтении меню,
не чаще одного раза за 10 минут на процесс. Параллельные чтения используют
одну операцию. Новые модели добавляются отдельными строками своего провайдера;
сходство названий не создаёт соответствие Kie/APIMart. Заполняются только пустые
тарифы и «—». Заданные цены, ID, действия, названия и пользовательские строки
сохраняются. Исключение — исправление известной ошибочной подписи Qwen2 Image Edit.
Документы с пользовательской версией, без префикса даты и `unified-`, не расширяются.

Публичные тарифы Kie читаются без ключа. Для APIMart используются серверный ключ
и API каталога/тарифов. Четыре параллельных чтения ограничивают нагрузку.
Неизвестный формат цены остаётся пустым. Ошибка источника сохраняет прежние строки
и цены; доступный второй источник продолжает обновление. Технические ошибки
отправляются в ai_logger. При записи актуальная строка перечитывается под общей
блокировкой, чтобы не затереть параллельный пользовательский импорт.

При запуске новый встроенный снимок дополняет предыдущий управляемый снимок
по тем же правилам сохранения. Пользовательский импорт и более новая версия
не заменяются. Никаких изменений схемы БД для этого не требуется.

Обновление исходного снимка и Markdown:

```powershell
node --env-file-if-exists=.env scripts/refresh-model-routes.cjs --snapshot
```

Обновление рабочей таблицы без замены подключения:

```powershell
docker compose exec -T media node scripts/refresh-model-routes.cjs
```

Команды читают каталоги и цены, без генераций и загрузок файлов. После правок
исходников обязательны `docker compose up -d --build`, `docker compose ps`
и `http://127.0.0.1:3000/api/health`.

Строка с опубликованным тарифом попадает в меню только при наличии модели
в соответствующем исполняемом каталоге. Публикация тарифа не подтверждает точную
цену любого запроса: расчёт и резерв используют отдельную котировку.
Тарифы за мегапиксели/токены без поддерживаемого расчёта не превращаются в
фиксированную цену. Платная генерация при обновлении каталогов не выполняется.

Общие маркетинговые страницы Kie сопоставляются с API-ID и режимом через
`config/kie-tariff-aliases.json`. Чужой явный `?model=` не подходит.
Режимы Kling std/pro сопоставляются с 720P/1080P; видео-преобразования и
анимация по аудио используют длительность именно переданного исходника
из проверенных сервером метаданных. Без метаданных точная цена неизвестна.

Qwen2 имеет отдельные формы генерации и редактирования; редактирование требует
`image_url`. В официальной странице text-to-image ошибочно повторён enum
image-edit; override сохраняет отдельный ID документированной операции.
Qwen2.1 использует отдельные схемы text-to-image/image-to-image; второй режим
требует `image_urls`.

`test/kie-pricing.test.js`, `scripts/check-kie-catalog.cjs` и контейнерная
сверка реальных каталогов/тарифов без платных генераций.
