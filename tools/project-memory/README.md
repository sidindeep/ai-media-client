## Поиск и проверка

Перед завершением изменений поведения или архитектуры сверять затронутые
контракты с исходниками, тестами и пользовательской документацией. Обновлять
только относящиеся к изменению спецификации; краткий отчёт не заменяет контракт.

Различать реализованное, запланированное и историческое поведение. Текущие
утверждения сопровождать датой проверки и ссылками на исходники или тесты.
При добавлении, переименовании, переносе или выводе спецификации из употребления
обновлять её запись в этой карте и проверять относительную ссылку в том же
пакете работ. Не переносить эти проверки в отдельную операцию Git finish.

Начинать с этой карты и точечного поиска по спецификациям. SQLite рекомендован: исходное дерево содержит более 50 текстовых файлов. Индекс пока не построен; для текущего объёма сведений доступен поиск rg. Векторные и внешние сервисы не включены. Наличие теста в ссылках означает найденное покрытие; результаты фактического запуска фиксировать отдельно.
