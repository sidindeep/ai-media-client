# История архитектуры

2026-10-01: следующий пакет модульности RouterAI сохраняет HTTP API, схему и
namespace записей. Сборка вынесена в server/routerai-module.js; HTTP использует
provider/admin, records владеет атомарными операциями записи/кошелька/журнала,
оркестратор получает client/records/conversion/content. Существующий транспорт
остаётся внутри процесса. Откат — вернуть прежнюю сборку, маршруты и billing
вместе; миграция данных не нужна. Приёмка пакета выполняется в текущем Compose
и изолированном PostgreSQL test-профиле без реальных платных генераций.

2026-10-01: по запросу владельца продолжен рефакторинг всего проекта по GI.
Первый пакет закрывает прямые вызовы worker из HTTP и SQL из Codex-оркестратора.
`server/codex-module.js` собирает provider/admin, worker-client и CodexRecords.
Generations владеет namespace codex и транзакцией записи/резерва/журнала;
кошелёк участвует через свои публичные транзакционные операции. HTTP также
переведён с accounts.pool на databaseState и modelConfigs. Форматы данных,
HTTP API, цены, идемпотентность и unknown сохранены; схема и целевая БД не меняются.
Откат пакета — вернуть его код совместно с composition/routes, сохраняя БД,
результаты worker и все прежние изменения. Общая приёмка и открытые пакеты
перечислены в docs/modularity-improvement-plan.md; остальные модули ещё в работе.

2026-09-28: начат переход HTTP к явным прикладным зависимостям в текущем
модульном монолите. Прежде `src/server/http.js` создавал Codex, RouterAI и
APIMart сервисы и содержал их маршруты вместе с маршрутами рабочих областей.
Теперь `server.js` собирает эти сервисы через `src/server/generation-services.js`,
одинаково при старте и восстановлении БД, а HTTP вызывает обработчики
`src/server/routes/generation.js` и `src/server/routes/workspace.js`.
SQL обновления профиля и составного sync read model перенесён из HTTP в
прикладные операции. Счётчик генераций без чата принадлежит
`generation-history`, административный ledger — `wallet`; `accounts`
составляет ответы через эти операции. Причина — явная граница сборки,
маршрутов и доступа к данным.
HTTP API, права, хранилище и схема БД сохранены; существующие потребители Vue,
legacy UI и Telegram не менялись. Откат к прежней сборке требует вернуть эти
файлы к предыдущей версии совместно, без преобразования данных. Проверки:
Compose build, healthy и `/api/health` с `ok: true`; контейнерный набор 246/246;
браузерный smoke с подставным Kie и тестовой PostgreSQL. Живые платные вызовы
по текущему указанию пользователя не выполнялись. Карта и дальнейший переход:
`specs/module-map.md`, `docs/modularity-improvement-plan.md`.

В следующем совместимом шаге Codex получил адаптер общего контракта приложения:
`src/providers/codex/application.js`. HTTP теперь берёт котировку, отправку и
чтение задания через него, сохраняя прежний JSON котировки для клиентов.
Платные операции, изображения, восстановление и резерв остаются в Codex billing;
адаптер не повторяет неизвестную отправку. Проверка: контрактный тест с
подставным billing, общий контейнерный набор и браузерный smoke. Откат адаптера
не требует миграции данных: маршруты могут снова вызвать billing напрямую.

Административные HTTP-маршруты вынесены в `src/server/routes/admin.js`.
Диагностические запросы по Kie, биллингу и операциям вызываются через методы
`accounts` вместо передачи `accounts.pool` в маршрут. Проверка роли остаётся
первым действием после проверки наличия account services. Публичные ответы и
SQL этих отчётов сохранены; откат — вернуть маршруты и вызовы отчётов в HTTP
без миграции БД. Контейнерные проверки выполняются в общем наборе.

Маршруты загрузки исходника и выдачи исходника, результата и ContentService
выделены в `src/server/routes/content.js`. HTTP сохраняет общий счётчик памяти
для одновременных загрузок и передаёт его через ограниченную операцию резерва.
Предел файла, доступ к аккаунту, streamed upload, fallback сохранения результата
и ответы для отсутствующих файлов сохранены. Откат — вернуть обработчики в HTTP;
данные и хранилище не менялись.

Клиентская котировка получила отдельного владельца состояния:
`web/src/composables/useLatestQuote.ts` хранит текущую котировку, ошибку,
состояние загрузки, debounce и номер запроса. `Composer.vue` передаёт ему
подготовленный запрос и может применить диагностическую цену только для
актуального номера. Сохранены прежние API и черновики. Откат — вернуть логику
таймера и номера в Composer; данные не преобразуются. Проверки: Vue type-check,
контейнерный набор и браузерный smoke со сменой модели и повтором отправки.

2026-09-22: пользовательские файлы веб-сервиса переведены с разрозненных

legacy-ссылок. Миграция зарегистрировала 25 доступных объектов и отметила 21
