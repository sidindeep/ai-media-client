# RouterAI

RouterAI доступен в меню выбора провайдера веб-студии для текста и изображений.
Сервер использует `https://routerai.ru/api/v1`; ключ задаётся через
`ROUTERAI_API_KEY` в приватной среде процесса. Ключ не передаётся браузеру.

Опубликованный каталог `config/routerai-models.json` содержит GPT OSS 20B и
GPT-4o mini для текста, а также GPT Image 1 Mini, GPT Image 1, GPT Image 2 и
FLUX.2 Klein 4B для изображений. Администратор дополнительно получает живой
каталог `GET /api/v1/models`. Все модели выбираются в общем меню студии, как
модели Kie: слева бренды, справа модели. Видео и аудио находятся в своих
вкладках; эмбеддинги, ранжирование и решения — во вкладке текста;
транскрибация — во вкладке аудио. Каталог кешируется на 10 минут.

Для специализированных моделей под формой есть «Расширенные настройки» с
дополнительными параметрами JSON. Основной текст берётся из промпта;
транскрибация принимает аудиофайл. Видео опрашивается до готовности и
сохраняется в приватное хранилище. Если автоматическая проверка не завершилась,
администратор может проверить статус видеозадачи в панели результата.

Обычный текст вызывает `/chat/completions`, изображения — `/images` или
`/chat/completions` в зависимости от модели. Специализированные модели используют
`/videos`, `/audio/speech`, `/audio/transcriptions`, `/embeddings`, `/rerank`
и `/decisions`. Для специализированных режимов параметры JSON надо указывать
по документации RouterAI конкретной модели. Бинарный результат сохраняется
как приватный файл, JSON — как ответ в истории.
Каждый запрос стоит 4 внутренних кредита по
`config/native-prices.json`, включая админский каталог. Перед отправкой кредиты резервируются, после
подтверждённого успеха списываются, после подтверждённого отказа возвращаются.
При неизвестном результате резерв сохраняется для ручной сверки; повторной
автоматической отправки нет.

Записи сохраняются в пространстве `routerai` таблицы `media_records`,
изображения — в приватном хранилище контента. История объединяет результаты
RouterAI с Kie и Codex. Стартовый пакет с ограничением GPT-only не даёт
доступа к RouterAI до разблокировки остальных моделей.
