# Стоимость и сверка расходов

Цель: отделить прогноз от фактического списания, не выдавать неизвестное за ноль. Источники: src/costs.js, tariffs.js, kie-session.js, price-audit.js, main.js.

## Факт и рубли

amount принимает конечное неотрицательное число либо десятичную строку. Пустое/некорректное => null; ноль допустим. Факт берётся только из creditsConsumed. На постановке задачи сохраняется rubPerCredit; charge использует этот курс, а для старых записей — текущий с признаком отсутствия исторического курса. Значение по умолчанию 0.51; настройка должна быть >0 и <=100000.

Суммы округляются до сотых. Дедупликация по providerId + (taskId или локальный id). День/месяц отбираются по локальной дате createdAt. Неизвестные суммы учитываются отдельно для success, fail, unknown, unconfirmed. Оценка не подставляется вместо факта.

## Оценка

При постановке сначала запрашивается оценка аккаунта Kie; при отсутствии/ошибке используется локальный тариф. KieSession очищает prompt/description и заменяет медиа-значения маркерами наличия по именам полей; это эвристическая редукция, не универсальная гарантия удаления любых чувствительных полей. Кэш оценки 5 минут.

Локальная quote поддерживает конкретные режимы Grok, Kling, Veo, Hailuo, Seedance, Imagen, Seedream. Требуется ровно одно совпадение описания тарифа без учёта регистра и точное совпадение единиц. Цена за секунду умножается на длительность; per video/image/request не экстраполируется произвольно. Неподдерживаемое сочетание => null.

Tariffs получает публичные страницы по 100 записей без пользовательского API-ключа; предел 30 страниц, таймаут страницы 15 секунд. Кэш 24 часа, одновременные обновления объединяются. При ошибке возвращается старый кэш или пустые строки с stale/error.

## Сверка

baseline и current содержат balance и сумму известных apiCredits. balanceSpent = baseline.balance - current.balance; apiSpent = current.apiCredits - baseline.apiCredits; difference = balanceSpent - apiSpent. Разница может отражать пополнение или внешние операции. Её нельзя распределять по моделям как доказанный расход.

## Аудит цен

plan строит базовый вход каждой Kie-модели и меняет по одному параметру цены, устраняя дубли по стабильному ключу. Это не полный декартов перебор сочетаний. compare: обе цены отличаются менее чем на 0.01 => match, иначе mismatch; только аккаунт => confirmed, только тариф => tariff-only, ни одной => unavailable.
