# Прогнозы и аналитика AI Media Client

Здесь сохраняются исследования аудитории, использования сервиса, нагрузки и объёма данных. Прогнозы содержат исходные данные, явные допущения и дату расчёта; они не заменяют фактическую статистику и нагрузочные измерения.

## Исследования

- [Прогноз пользователей нагрузки и логов на первые два месяца](2026-10-02-launch-forecast.md) — исходная оценка от 2 октября 2026 года.
- [Калькулятор прогноза](2026-10-02-launch-calculator.html) — автономный файл для открытия в браузере, все три сценария доступны внутри.
- [Исходные параметры модели](2026-10-02-launch-model.json) — допущения, сценарии и рассчитанные значения в машиночитаемом виде.
- [Редактируемый источник калькулятора](2026-10-02-launch-calculator.fragment.html) — источник автономной версии.

## Продолжение исследования

При следующем обращении сначала прочитать отчёт и параметры модели. Сопоставить гипотезы с агрегированной статистикой реальных размещений и использования. Для следующей версии добавить новый отчёт с датой, сохранив этот исходный прогноз для сравнения.

Не хранить здесь персональные данные, сырые логи, промпты, ключи, фото или видео. Сохранять агрегаты, компактные результаты и ссылки на источники. Различать активных пользователей, тестовую команду, технические логи ai_logger и бизнес-записи основной БД.
