# APIMart: администраторский маршрут генераций

Статус 2026-09-28: каталог ключа содержит 307 ID. Открыты все категории.
Старые completion-модели направляются в `/v1/completions`, а не в чат;
Responses-модели определяются по `supported_endpoint_types`.

## Контракт

- `APIMART_API_KEY` хранится в серверной среде. `src/server/config.js` передаёт
  его только серверному клиенту. Каталог браузера содержит ID, название,
  режим, параметры и ссылку на документацию; ключ не передаётся.
- Только администратор может читать `/api/apimart/models`, создавать и читать
  `/api/apimart/jobs`. Все модели берутся из каталога APIMart и кешируются
  на 10 минут. Нет ручного добавления модели по строке из браузера.
  Режимы text/image/video/audio выбирают модели по `category`; неизвестная
  категория относится к тексту. APIMart сохраняется при переключении вкладок.
  В текстовом режиме UI предпочитает `gpt-4o-mini`, если нет сохранённого выбора.
- Запрос содержит UUID, модель, промпт до 20 000 символов и объект параметров
  до 16 КБ. Обязательность промпта и полей берётся из схемы модели.
  `requestId` связывает повтор с прежней записью; другая модель, промпт или
  чат или параметры с тем же ID отклоняются. Текст использует `stream:false`.
- `config/apimart-schemas.json` хранит параметры и endpoints из официальных
  страниц. Обновление: `node scripts/sync-apimart-schemas.cjs`; оно не запускает
  генерации. `catalog.js` сопоставляет алиасы и специальные API: Midjourney,
  Responses/Completions/Edits, speech, transcription и аудиочат.
  UI использует общие ModelCatalogPicker и AdvancedParameters. Модели без
  опубликованной схемы получают поле дополнительных параметров JSON.
- Для полей изображений загруженные файлы хранятся как собственные `content:`
  ссылки. Перед генерацией сервер читает их от имени аккаунта, загружает через
  `POST /v1/uploads/images`, подставляет выданные APIMart URL и связывает
  исходники с задачей. Ограничение — 20 МБ на изображение, 50 МБ суммарно.
  Прямой base64 в generation API APIMart больше не поддерживается. Пользователь
  также может вставить публичные URL в поля модели. URL загрузки живёт 72 часа.
  Источник: [Upload Image](https://docs.apimart.ai/en/api-reference/uploads/images).
  Whisper принимает свой аудиоисходник до 25 МБ через multipart API.
- Задача хранится в namespace `apimart` выбранного аккаунта. История,
  страницы, delta-чтение и удаление архивного чата включают этот namespace.
  События создания, отправки и исхода пишутся в общий журнал.
- Внутренний тариф пока отсутствует. Администратор платит в APIMart напрямую;
  кредитный кошелёк приложения не затрагивается. Обычным пользователям API
  запрещён. `/api/apimart/quote` берёт эффективный тариф через
  `/api/pricing/model?model=...`, принимает только модель из каталога и
  рассчитывает приблизительные токены промпта как UTF-8 bytes / 4 и 512
  выходных токенов. 512 — число предполагаемых токенов, не кредитов.
  UI показывает `≈` полную оценку запроса в кредитах APIMart и USD до отправки.
  Под кнопкой UI показывает формулу: оценка входных токенов × входной
  тариф за токен + 512 × выходной тариф за токен. Это предотвращает повторное
  умножение уже готовой суммы на 512.
  Тарифы с кешированием, ступенями или иной единицей расчёта не оцениваются.
  Для медиа полная оценка учитывает поддерживаемые тарифы за изображение,
  секунду или музыкальную задачу, выбранные параметры и число результатов.
  Для неизвестной формы тарифа возвращается `unavailable`.
  Для видео с тарифом `per_second` и опубликованной картой
  `resolution_paid_prices` выбирается точное разрешение; отсутствующий вариант
  остаётся без оценки.
  Если приложено исходное видео и его длительность не подтверждена, оценка
  недоступна: APIMart учитывает длительность исходника вместе с результатом.
  Служебные `token`-ключи в `billing_tier_paid_prices` не заменяют цену за
  секунду. В частности, Seedance 2.5 должен пересчитываться при выборе 480p,
  720p или 1080p, а не использовать общую `paid_price` для всех вариантов.
  Для изображения с `tiered_token` и без опубликованной цены выбранного
  разрешения общая `paid_price` не принимается за полную цену генерации.
  После текста простой тариф пересчитывается по фактическим токенам и
  показывается как расчёт. `usage` не выдаётся за сумму списания.
  Для асинхронных задач `cost` и `credits_cost` сохраняются с `confirmed:true`
  и показываются как расход APIMart. Неизвестный расход не становится нулём.
- ID медиа-задачи сохраняется до опроса. Опрос `/v1/tasks/{id}` либо
  `/v1/music/tasks/{id}` продолжается после перезапуска и повторяет временные
  ошибки чтения; платный POST не повторяется. Без сохранённого ID неизвестный
  исход становится `unknown`. Опрос ограничен 360 итерациями по 5 секунд
  плюс время HTTP-запросов. Синхронные URL/base64-результаты также сохраняются.
  Медиа переносятся в общий content service с привязкой к namespace `apimart`;
  при недоступности сохранения URL остаётся доступным до срока провайдера.
- APIMart документирует `GET /v1/usage`: `data.total.amount_usd` и
  `data.total.credits` — подтверждённый агрегированный расход за период, а не
  цена конкретной генерации. `GET /v1/user/balance` подключён к общему
  `/api/admin/provider-status` и показывает `remain_credits` аккаунта.
  `GET /v1/balance` возвращает только лимит ключа; у текущего ключа он
  безлимитный и не равен остатку кошелька. `/v1/usage` пока не подключён.
  Источники:
  [usage](https://docs.apimart.ai/en/api-reference/account/usage.md),
  [user balance](https://docs.apimart.ai/en/api-reference/account/user-balance.md),
  [token balance](https://docs.apimart.ai/en/api-reference/account/token-balance.md).
- Меню использует общую группировку моделей по разработчику, как у Kie и
  RouterAI; APIMart остаётся именем поставщика. Неизвестные семейства остаются
  в группе APIMart.
