# APIMart

APIMart появляется в меню поставщиков только у администратора. Ключ задаётся
серверной переменной `APIMART_API_KEY` в `.env`; браузер его не получает.
Базовый URL: `https://api.apimart.ai/v1`.

Для Kie GPT Image 2 Text to Image администратор может включить автовыбор Kie/APIMart.
При генерации одного изображения по тексту с общим соотношением сторон,
разрешением 1K/2K/4K и непрозрачным фоном сервер
сравнивает закупочную оценку в USD и передаёт запрос выбранному поставщику.
Под формой показаны выбранный поставщик и ориентировочная закупочная сумма.
Если выбран APIMart, оплата идёт напрямую с его счёта; если Kie — по обычному
правилу кредитов приложения. [План расширения](cost-routing-plan.md).

Студия показывает весь каталог ключа из `GET /v1/models?expand=category`
по вкладкам «Текст», «Изображение», «Видео», «Аудио». Выбор APIMart сохраняется
при переключении вкладок. Каталог кешируется на 10 минут. Если API не возвращает
каталог, меню объясняет ошибку, а отправка недоступна.

Параметры модели описаны в `config/apimart-schemas.json`, полученном из
документации APIMart. Основные настройки и дополнительные параметры используют
общие компоненты студии. Исходные изображения можно загрузить через кнопку
источников: перед генерацией сервер отправит файл в `POST /v1/uploads/images`
и передаст полученную ссылку в поле модели. Публичную ссылку можно вставить через
свёрнутый пункт «Добавить изображение по ссылке»; при загрузке файла он не нужен.
APIMart хранит загруженный файл 72 часа; прямой base64 в запросе генерации
больше не поддерживается.
Whisper принимает загруженный аудиофайл. Для моделей без опубликованной схемы
остаются промпт и дополнительные параметры JSON.
Обновление схем без генераций: `node scripts/sync-apimart-schemas.cjs`.

Текст направляется в Chat Completions, Responses или legacy Completions/Edits
согласно модели. Изображения и видео используют соответствующие generation API;
Midjourney — `/v1/midjourney/generations`; Suno и Flow Music — `/v1/music/generations`.
Озвучка использует `/v1/audio/speech`, аудиодиалог — Chat Completions с аудиовыходом,
распознавание — `/v1/audio/transcriptions`. Наличие ID в каталоге не гарантирует,
что APIMart продолжает обслуживать старую модель.

Администраторские запросы APIMart не резервируют и не списывают кредиты
приложения. APIMart списывает оплату со своего баланса. Для моделей с простым
тарифом входных и выходных токенов кнопка показывает предварительную оценку
в кредитах APIMart и USD. Она использует приблизительное число токенов промпта
и 512 токенов ответа; реальный ответ может быть длиннее или короче. Число 512
обозначает токены, не кредиты APIMart. На кнопке показана оценка полной
генерации в кредитах APIMart и USD.
Для отладки под кнопкой показано разложение по входным и выходным токенам:
тариф за один токен умножается на ожидаемое число токенов, затем суммы
складываются. Сумма на кнопке уже включает все 512 предполагаемых токенов
ответа; умножать её на 512 повторно нельзя.
Для медиа кнопка считает полную сумму по поддерживаемому тарифу, выбранному
разрешению, количеству, длительности и режиму. Для неподдерживаемой схемы тарифа
оценка скрывается. Видео с референсным видео остаётся без оценки, пока его
длительность не подтверждена: поставщик тарифицирует исходник и результат.
После текстового ответа история показывает расчёт по токенам;
для асинхронных задач поля `cost` и `credits_cost` из ответа задачи показываются
как подтверждённый расход APIMart. Обычным пользователям не доступны ни
меню, ни API маршрута.
В меню модели сгруппированы по разработчику; APIMart остаётся поставщиком.
Для уже списанных сумм APIMart документирует `GET /v1/usage`: поля
`data.total.amount_usd` и `data.total.credits` относятся к выбранному периоду,
а не к отдельному ID генерации. `GET /v1/user/balance` показывает остаток
кредитов аккаунта в меню поставщиков. Лимит отдельного ключа из
`GET /v1/balance` не показывается: при `unlimited_quota` он равен `-1` и не
характеризует денежный остаток. `/v1/usage` пока не подключён к приложению.
Задания хранятся в namespace `apimart` и отображаются в общей истории.
ID асинхронной задачи сохраняется до опроса. После перезапуска опрос продолжается,
готовые файлы переносятся в общее хранилище контента. Если ID не был получен или
сохранён, неопределённый исход отмечается `unknown`. Сервис не повторяет платный
POST автоматически. Временные ошибки чтения статуса повторяются.

Проверка каталога 2026-09-28: 307 ID, включая 46 моделей изображений,
56 моделей видео и 12 моделей аудио. Legacy `babbage-002` не обслуживается
маршрутом чата и теперь направляется в Completions. Доступность конкретных
моделей зависит от APIMart; все платные модели подряд не прогоняются.
