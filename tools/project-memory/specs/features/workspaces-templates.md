# Вкладки, черновики и шаблоны

Цель: пользователь не теряет редактируемый запрос при смене вкладки и закрытии. Неполная форма является допустимым черновиком.

## Черновики

snapshotWorkspaces фиксирует текущую форму и сохранённые состояния вкладок: provider/model, поля, вложенные редакторы, локальные ref, метаданные исходников и выбор предпросмотра. Файлы заранее переводятся в локальное хранилище; WeakMap предотвращает повторное сохранение одного объекта File, неуспешная операция удаляется из кэша.

Снимок version=1, active, tabs. Главный процесс принимает 1–5 вкладок. Сохранение откладывается на 600 мс после изменений. Снимки могут готовиться асинхронно, но пишутся в порядке захвата, чтобы старый не заменил новый.

При восстановлении модель ищется по ID и провайдеру. Отсутствующая модель вызывает ошибку. Восстанавливаются вложенные редакторы, ref и значения; обязательная пустая длительность получает допустимое значение. Код сохраняет search/filter в снимке, но не гарантирует точное восстановление фильтров: при восстановлении они очищаются.

beforeunload блокирует закрытие до успешного сохранения. Ошибка оставляет окно открытым; повторная попытка разрешена. Это не защита от аварийного завершения процесса до записи.

## Шаблоны и избранное

PromptTemplates сохраняет имя после trim (непустое, до 120 символов) и исходный непустой текст (до 200000 символов). Редактирование требует существующего ID; удаление мягкое, deleted=true; list скрывает удалённые. Подстановка шаблона не должна сама запускать платную генерацию.

Избранные модели сохраняются в preferences по model-favorites; допустимость ID проверяет главный процесс. Рабочая вкладка задачи хранится как workspace 1–5, недопустимое значение заменяется на 1.

Источники: src/drafts.js, prompt-templates.js, templates-ui.js, renderer.js, main.js.
Проверки: test/prompt-templates.test.js; test/ui-smoke.cjs содержит сценарии формы, шаблонов и черновиков. Отдельного unit-теста drafts.js нет; полнота закрытия и восстановления требует smoke-проверки.
