# Роли БД и миграции

Начиная с v10, `src/database/schema.sql` — неизменяемая базовая схема. Новые
миграции лежат в `src/database/migrations/`; при старте проверяются версия и
SHA-256. Переносы строк LF/CRLF приводятся к одному виду; ранее записанный
хеш v10 из checkout со смешанными переносами принимается только для той же
канонической схемы. Приложение откажется работать с
неизвестной более новой схемой или изменённой миграцией. В v11–v12 добавлены индекс inbox и восстановление
неопределённой платёжной команды; v13 закрепляет инварианты workspace и два
измеренных индекса подсчётов; v14 добавляет журнал системных ошибок.

## Разделение ролей

1. Создайте отдельную PostgreSQL роль с `LOGIN`, `NOSUPERUSER`, `NOCREATEDB`,
   `NOCREATEROLE`, `NOREPLICATION`, `NOBYPASSRLS`. Имя задайте
   `MEDIA_RUNTIME_ROLE`. Пароль задавайте через защищённый секретный менеджер;
   не сохраняйте его в Git или истории терминала.
2. В `DATABASE_MIGRATION_URL` укажите прежнее подключение владельца таблиц.
   Выполните `docker compose run --rm media node scripts/migrate-schema.cjs`.
   Миграции идут под advisory lock в одной транзакции.
3. Выполните `docker compose run --rm media node scripts/grant-runtime-role.cjs`.
   Скрипт выдаёт роли DML на продуктовые таблицы и только SELECT на журналы
   схемы. После каждой будущей миграции повторите выдачу прав для новых таблиц.
4. В `DATABASE_URL` укажите новую ограниченную роль и задайте
   `MEDIA_DB_MIGRATE=false`. Пересоберите Compose, проверьте `docker compose ps`,
   `/api/health` и вход, историю, создание черновика, платёжный test-сценарий.
   Проверьте `current_user` и флаги `pg_roles` через это подключение.
5. Если проверка не прошла, восстановите прежний `DATABASE_URL` и значение
   `MEDIA_DB_MIGRATE`, пересоберите Compose и исправьте конкретный недостающий
   GRANT. Не поднимайте привилегии runtime роли до superuser.

В текущем Compose подключение к общей действующей БД остаётся прежним, пока
оператор не задаст учётные данные новой роли. Отдельный PostgreSQL test profile
проверяет, что приложение читает схему и выполняет DML под ролью без DDL-прав.
