# APIMart

APIMart появляется в меню поставщиков только у администратора. Ключ задаётся
серверной переменной `APIMART_API_KEY` в `.env`; браузер его не получает.
Базовый URL: `https://api.apimart.ai/v1`.

На первом этапе студия показывает текстовые модели категории `chat` из
`GET /v1/models?expand=category` и отправляет не потоковый
`POST /v1/chat/completions`. Каталог кешируется на 10 минут. Если APIMart не
возвращает каталог, меню остаётся доступным с объяснением ошибки, а отправка
недоступна. Изображения, видео и аудио не включены: их асинхронные задачи,
параметры и результат требуют отдельного контракта.
Модели `babbage-002` и `davinci-002` исключены: APIMart помечает их как `chat`,
но маршрут `/chat/completions` их не обслуживает. При первом открытии по
умолчанию выбирается `gpt-4o-mini`, если она есть в каталоге.

Пока не утверждены внутренние тарифы, администраторские запросы APIMart не
резервируют и не списывают кредиты приложения. Расход учитывается самим
APIMart. Обычным пользователям не доступны ни меню, ни API маршрута.
Задания хранятся в namespace `apimart` и отображаются в общей истории.
После неоднозначного сбоя или перезапуска запрос отмечается `unknown`; сервис
не делает повторный POST, чтобы избежать двойного расхода.

Проверка текущего ключа 2026-09-28: каталог доступен. Живой запрос
`babbage-002` к `/chat/completions` вернул HTTP 404; `gpt-4o-mini` ответила
HTTP 200 на том же маршруте. Доступность каталога и баланс могут меняться.

Документация API: [список моделей](https://docs.apimart.ai/en/api-reference/texts/models/list),
[чат без потока](https://docs.apimart.ai/en/api-reference/texts/general/chat-completions-nostream).
